# Choosing components

Avara UI has two kinds of page. A **component** is one piece of UI (a dialog, a data table, a dock). A **website section** is a whole block of a page (a hero, pricing, a footer) composed from the library's own components, so installing one pulls its pieces in as dependencies.

For a page, start with sections, then reach for components to fill gaps. For a control inside an app, use components.

Each name below is a docs page slug. Its summary, install command and Markdown are in the agent index: `https://avaraui.com/agent/components.json`.

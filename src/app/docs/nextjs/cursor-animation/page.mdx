# Cursor Animation

An interactive, fully responsive custom cursor component with smooth physics, particle trails, magnetic alignment, and custom label badges.

`CursorAnimation` replaces or enhances standard pointer interactions over designated containers with customizable animations, seamless dark mode support, and fluid responsive physics for both desktop and mobile devices.

## Installation

Copy the `CursorAnimationBlock.tsx` component into your `src/components/custom/blocks/` directory.

### Dependencies

Ensure you have `lucide-react` installed:

```bash
npm install lucide-react
```

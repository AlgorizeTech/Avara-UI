# Marquee

An infinite, seamless scrolling container ideal for logos, testimonials, and image galleries.

This `MarqueeBlock` is engineered to be **flawless**. By exactly duplicating the content and using a precise CSS calculation (`calc(-100% - gap)`), the animation loops infinitely without any stuttering, lagging, or "snap back" resets that plague older implementations.

## Usage

Simply place the elements you want to loop inside the `<MarqueeBlock>`. You only need to provide **one** set of items; the component will duplicate them automatically to create the seamless loop.

```tsx
import { MarqueeBlock } from "@/components/custom/blocks/MarqueeBlock";

const logos = ["Vercel", "Stripe", "Supabase", "Linear", "Figma"];

export default function LogoSection() {
  return (
    <div className="w-full py-12">
      <MarqueeBlock
        direction="left"
        speed="normal"
        pauseOnHover
        fade
        gap="4rem"
      >
        {logos.map((logo, i) => (
          <div key={i} className="text-xl font-bold text-zinc-400">
            {logo}
          </div>
        ))}
      </MarqueeBlock>
    </div>
  );
}
```

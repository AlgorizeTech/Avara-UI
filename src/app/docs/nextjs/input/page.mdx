# Input

A foundational, omni-purpose form primitive. This component handles all major input types (text, password, email, search, file upload, textareas, selects, checkboxes, and radios) while maintaining a consistent visual hierarchy and flawless accessibility.

## Interactive Showcase

Use the control panel below to test the different input types, sizing options, and structural variants.

- **The `glow` variant** applies a deep, luminous ambient shadow using your selected theme color when the input comes into focus.
- **Checkboxes & Radios** automatically bypass the standard input wrappers to render native-feeling, accessible boolean options that still inherit your custom hex colors via the `accent` CSS property.
- **The `file` type** completely restyles the native, ugly browser file input into a beautiful drag-and-drop zone.

## Installation

### 1. Install Dependencies

This component relies on `lucide-react` for the standard UI icons (Eye, Search, Mail, AlertCircle, Upload, ChevronDown).

```bash
npm install lucide-react
```

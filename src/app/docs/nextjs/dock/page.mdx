# Dock

A premium, macOS-inspired navigation dock featuring real-time physics magnification, floating label tooltips, active application indicators, and notification badges. Highly customizable via direct layout and physics props, it adapts seamlessly between desktop floating tooltips and touch-safe mobile layouts.

## Interactive Showcase

Hover across the dock icons on desktop to experience unclipped Framer Motion magnification physics. Click any icon to switch the active indicator dot.

## Installation

### Dependencies

This component requires **Framer Motion** for real-time cursor tracking and spring physics, and **Lucide React** for UI icons.

```bash
npm install framer-motion lucide-react
```

### Copy the Component

Copy the core engine code directly from the Component tab in the Interactive Showcase above and place it in components/custom/blocks/DockBlock.tsx.

## Usage Architecture

The `<Dock>` component accepts an array of items along with optional dimension and physics parameters (containerHeight, gap, baseSize, magnification, and distance) to tune the appearance and responsiveness of the zoom effect.

```
import { Dock } from "@/components/custom/blocks/DockBlock";
import { Home, Mail, Terminal, Settings } from "lucide-react";

export default function BottomNav() {
  const dockItems = [
    { id: "home", label: "Home", icon: <Home className="w-full h-full"/>, isActive: true },
    { id: "mail", label: "Mail", icon: <Mail className="w-full h-full"/>, badge: "3" },
    { id: "terminal", label: "Terminal", icon: <Terminal className="w-full h-full"/> },
    { id: "settings", label: "Settings", icon: <Settings className="w-full h-full"/> },
  ];

  return (
    <div className="fixed bottom-6 left-1/2 -translate-x-1/2 z-50">
      <Dock baseSize="{48}" containerHeight="{68}" distance="{140}" gap="{14}" items="{dockItems}" magnification="{82}"/>
    </div>
  );
}
```

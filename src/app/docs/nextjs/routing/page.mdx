# Pages & Routing

Next.js uses a file-system based router where folders are used to define routes.

## File-based Routing

Next.js uses a file-system based router where folders are used to define routes:

```bash
app/
├── page.js        → /
├── about/
│   └── page.js    → /about
└── blog/
    ├── page.js    → /blog
    └── [slug]/
        └── page.js → /blog/:slug
```

## Creating Routes

To create a route, create a `page.js` file inside the `app` directory:

```jsx
// app/page.js
export default function Home() {
  return <h1>Hello, Home page!</h1>
}
```

```jsx
// app/about/page.js
export default function About() {
  return <h1>About Us</h1>
}
```

## Dynamic Routes

To create dynamic routes, wrap the folder name in square brackets:

```bash
app/
└── blog/
    ├── page.js         → /blog
    └── [slug]/
        └── page.js     → /blog/:slug
```

Access the dynamic parameter in your component:

```jsx
// app/blog/[slug]/page.js
export default function Post({ params }) {
  return <h1>Post: {params.slug}</h1>
}

export async function generateMetadata({ params }) {
  return {
    title: `Post: ${params.slug}`
  }
}
```

## Nested Routes

Create nested layouts by adding a `layout.js` file in a folder:

```jsx
// app/dashboard/layout.js
export default function DashboardLayout({ children }) {
  return (
    <div>
      <nav>Dashboard Navigation</nav>
      <main>{children}</main>
    </div>
  )
}
```

```jsx
// app/dashboard/page.js
export default function DashboardPage() {
  return <h1>Dashboard</h1>
}
```

```jsx
// app/dashboard/settings/page.js
export default function SettingsPage() {
  return <h1>Settings</h1>
}
```

## Route Groups

Organize routes without affecting the URL path by using route groups (folders in parentheses):

```bash
app/
├── (marketing)/
│   ├── page.js          → /
│   └── about/
│       └── page.js      → /about
└── (shop)/
    ├── layout.js
    ├── page.js          → /shop
    └── cart/
        └── page.js      → /shop/cart
```

## Parallel Routes

Render multiple pages in the same layout using slots:

```jsx
// app/layout.js
export default function Layout({ children, dashboard }) {
  return (
    <div>
      <main>{children}</main>
      <aside>{dashboard}</aside>
    </div>
  )
}
```

```bash
app/
├── layout.js
├── page.js
└── @dashboard/
    └── page.js
```

## Loading UI

Create loading states for better user experience:

```jsx
// app/dashboard/loading.js
export default function Loading() {
  return <p>Loading dashboard...</p>
}
```

## Error Handling

Handle errors gracefully with error boundaries:

```jsx
// app/dashboard/error.js
'use client'
 
export default function Error({ error, reset }) {
  return (
    <div>
      <h2>Something went wrong!</h2>
      <button onClick={() => reset()}>Try again</button>
    </div>
  )
}
```

## Route Handlers

Create API endpoints with Route Handlers:

```js
// app/api/route.js
export async function GET(request) {
  const data = { message: 'Hello from API' }
  return Response.json(data)
}
```

## Link Component

Use the `Link` component for client-side navigation:

```jsx
import Link from 'next/link'

export default function Navigation() {
  return (
    <nav>
      <Link href="/">Home</Link>
      <Link href="/about">About</Link>
    </nav>
  )
}
```

## Programmatic Navigation

Navigate programmatically using the `useRouter` hook:

```jsx
'use client'
import { useRouter } from 'next/navigation'

export default function Button() {
  const router = useRouter()
  
  return (
    <button onClick={() => router.push('/dashboard')}>
      Go to Dashboard
    </button>
  )
}

# Alert

A versatile and highly customizable alert component used to display important messages, warnings, and system feedback to the user.

## Interactive Showcase

Alerts come in several semantic types (`success`, `danger`, `warning`, `info`, `primary`, `secondary`, and `dark`) to communicate different states.

Use the control panel below to toggle between solid and outline visual variants, swap out icons (including emojis), and test dismissible functionality and rich HTML children.

<AlertShowcase />

## Installation

1. Create the `Alerts.tsx` component inside your project and paste the generated code.
2. Install the required icon library (if you intend to use the built-in Lucide icons):

```bash
npm install lucide-react
```


## Custom SVGs
If you don't want to use standard strings or Lucide icons, you can always pass a raw SVG element directly into the icon prop within your own codebase.

```
"use client";

import { Alert } from "@/components/custom/blocks/Alerts";

export default function CustomSvgDemo() {
  return (
    <Alert 
      type="warning" 
      title="Custom SVG" 
      message="Passing a raw SVG element." 
      dismissible={isDismissible}
      icon={
        <svg className="w-5 h-5" fill="currentColor" viewBox="0 0 20 20">
          <path fillRule="evenodd" d="M8.257 3.099c.765-1.36 2.722-1.36 3.486 0l5.58 9.92c.75 1.334-.213 2.98-1.742 2.98H4.42c-1.53 0-2.493-1.646-1.743-2.98l5.58-9.92zM11 13a1 1 0 11-2 0 1 1 0 012 0zm-1-8a1 1 0 00-1 1v3a1 1 0 002 0V6a1 1 0 00-1-1z" clipRule="evenodd" />
        </svg>
      } 
    />
  );
}
```

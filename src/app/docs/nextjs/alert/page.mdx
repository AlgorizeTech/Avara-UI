# Alert

A versatile and highly customizable alert component used to display important messages, warnings, and system feedback to the user.

## Semantic Types

Alerts come in several semantic types to communicate different states: `success`, `danger`, `warning`, `info`, `primary`, `secondary`, and `dark`.

## Preview

  <Alert type="danger" title="Error" message="Something went wrong. Please try again." />

  <Alert type="info" title="Information" message="Here's some helpful information for you." />

## Variants
You can display alerts using the solid (default) or outline visual variant to match your UI's hierarchy.

<Alert type="success" variant="outline" title="Outline Success" message="This is an outline variant." />
<Alert type="danger" variant="solid" title="Solid Error" message="This is a solid variant." />

</div>

## Code
```tsx
"use client";

import { Alert } from "@/components/custom/alerts";

  return (
    <div className="grid grid-cols-2 gap-4">

    </div>

```

## Dismissible & Rich Content
Set dismissible={true} to allow users to close the alert. You can also pass children to render rich HTML like lists or buttons inside the alert body.

## Code
```tsx
"use client";

import { Bell } from "lucide-react";
import { Alert } from "@/components/custom/alerts";

export default function RichAlertDemo() {
  return (
    <div className="flex flex-col gap-4">
      {/* Standard Dismissible Alert */}
      <Alert 
        type="info" 
        dismissible={true} 
        icon={<Bell className="w-5 h-5" />} 
        title="Notification" 
        message="You can close this alert by clicking the X button." 
        onDismiss={() => console.log('Alert closed!')}
      />
      
      {/* Rich HTML Content */}
      <Alert type="primary" title="System Update Available" dismissible={true}>
        <p className="text-sm mb-2">New features and improvements:</p>
        <ul className="text-sm list-disc list-inside space-y-1 mb-3">
          <li>Enhanced dashboard performance</li>
          <li>New alert component with customization</li>
        </ul>
        <div className="flex gap-2">
          <button className="bg-blue-600 text-white px-3 py-1 rounded text-sm cursor-pointer">
            Update Now
          </button>
        </div>
      </Alert>
    </div>
  );
}
```

# Card

A flexible container used to group related information and actions together in a visually distinct box.

Building a UI entirely out of raw `div` tags quickly leads to inconsistent padding, mismatched border radiuses, and spaghetti code. The `CardBlock` provides a set of highly composable components (`CardHeader`, `CardContent`, `CardFooter`) that automatically manage their own internal spacing, ensuring your layouts always look perfectly balanced regardless of what content you put inside them.

## Usage

The Card component uses a composable architecture. You wrap your content in the main `<Card>` container, and then use the sub-components to structure the interior layout.

You do not need to use all the sub-components. For example, metric/statistic cards often omit the `<CardFooter>` entirely.

```tsx
import {
  Card,
  CardHeader,
  CardTitle,
  CardDescription,
  CardContent,
  CardFooter,
} from "@/components/custom/blocks/CardBlock";

export default function CheckoutForm() {
  return (
    <Card variant="bordered" className="max-w-md">
      <CardHeader>
        <CardTitle>Payment Details</CardTitle>
        <CardDescription>
          Enter your credit card information below.
        </CardDescription>
      </CardHeader>

      <CardContent>
        <div className="space-y-4">
          <input
            type="text"
            placeholder="Card Number"
            className="w-full p-2 border rounded"
          />
        </div>
      </CardContent>

      <CardFooter>
        <button className="w-full bg-blue-600 text-white p-2 rounded">
          Submit Payment
        </button>
      </CardFooter>
    </Card>
  );
}
```

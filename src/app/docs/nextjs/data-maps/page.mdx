# Data Maps

{/* A beautiful map component to visualize your geographic data points */}

A React-Leaflet based choropleth map component for beautifully visualizing geographic data and trends without clunky map tiles.

## Installation

Ensure you have `leaflet` and `react-leaflet` installed. If not, install them using:

```bash
npm install leaflet react-leaflet
npm install -D @types/leaflet
```



## Usage

Pass an array of data points to the component. Each point requires an `id` (the 3-letter ISO country code) and can display rich metrics like active users and new trends in an elegant hover card.

<div id="datamap-docs-fill">

```tsx
import { DataMaps } from "@/components/custom/blocks/DataMapsBlock";

export default function AnalyticsDashboard() {
  const mapData = [
    { id: "CHN", name: "China", flag: "🇨🇳", active: 13.7, activeTrend: "up", new: 0.1, newTrend: "down" },
    { id: "IND", name: "India", flag: "🇮🇳", active: 8.4, activeTrend: "up", new: 0.3, newTrend: "up" },
    { id: "USA", name: "United States", flag: "🇺🇸", active: 11.2, activeTrend: "down", new: 0.5, newTrend: "down" },
  ];

  return (
    <div className="w-full h-[500px]">
      <DataMaps dataPoints={mapData} zoom={2} variant="fill" />
    </div>
  );
}
```

</div>

## Best Practices & Guidelines

<div className="flex flex-col gap-4 my-6 not-prose">
  <div className="p-5 rounded-xl border border-blue-200 dark:border-blue-900/50 bg-blue-50/50 dark:bg-blue-950/20">
    <h4 className="text-base font-semibold text-blue-900 dark:text-blue-300 mb-1">Dynamic Imports</h4>
    <p className="text-blue-800 dark:text-blue-400/80 text-sm">Always ensure that any component relying on <code>react-leaflet</code> is dynamically imported with <code>{"{ ssr: false }"}</code>. Leaflet relies on the browser's <code>window</code> object and will crash your Next.js app if executed on the server.</p>
  </div>
  <div className="p-5 rounded-xl border border-amber-200 dark:border-amber-900/50 bg-amber-50/50 dark:bg-amber-950/20">
    <h4 className="text-base font-semibold text-amber-900 dark:text-amber-300 mb-1">GeoJSON Caching</h4>
    <p className="text-amber-800 dark:text-amber-400/80 text-sm">By default, the map fetches the world map GeoJSON from a remote CDN. For production environments, it is highly recommended to download the <code>custom.geo.json</code> file and host it locally in your <code>public</code> directory to reduce latency.</p>
  </div>
</div>

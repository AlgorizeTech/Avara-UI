# Support Dashboard

A premium, 3-pane helpdesk interface designed for customer support teams. Features include a scrollable ticket queue, a rich conversation thread, and a comprehensive user details panel with property dropdowns.

## Interactive Showcase

Explore the different architectural variants of the Support Dashboard. Switch between the classic split-view (`default`), a cleaner borderless layout (`minimal`), or a stunning backdrop-blurred panel (`glass`).

Click on a ticket in the left sidebar to view the conversation thread and the customer's SLA/Properties in the right sidebar. Accent colors and active states will adapt to the selected Theme Color.

## Installation

### 1. Install Dependencies

This component relies heavily on `lucide-react` for its interface iconography. Run the following command:

```bash
npm install lucide-react
```

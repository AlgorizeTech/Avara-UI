# Support Dashboard

A premium, 3-pane helpdesk interface designed for customer support teams. Features include a scrollable ticket queue, a rich conversation thread, and a comprehensive user details panel.

## Interactive Preview

Click on a ticket in the left sidebar to view the conversation thread and the customer's SLA/Properties in the right sidebar.

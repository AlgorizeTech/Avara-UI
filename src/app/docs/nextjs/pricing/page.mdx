# Pricing Components

A collection of highly-converting, responsive pricing sections. Whether you need traditional tiered subscription cards with toggleable billing cycles or an interactive, usage-based quote builder, these components are designed to maximize conversions.

## Interactive Showcase

Use the control panel below to flip between the **Tiered Cards** layout and the **Interactive Builder**. You can customize the visual structure of the cards (`default`, `premium`, `elegant`) and apply global color themes that cascade instantly across buttons, gradients, glows, and badges.

<PricingShowcase />

## Installation

1. Install the required dependencies (`gsap` is required for the Interactive Builder animations, and `lucide-react` handles the icons):

```bash
npm install lucide-react gsap
```

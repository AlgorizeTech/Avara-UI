# Hero Video Player

An embeddable, hardware-accelerated video preview component designed for landing pages and high-conversion hero sections. Features a glassmorphism CTA button, automatic dark/light mode responsiveness, and full keyboard accessibility.

## Best Practices & Guidelines

<div className="flex flex-col gap-4 my-6 not-prose">
  <div className="p-5 rounded-xl border border-blue-200 dark:border-blue-900/50 bg-blue-50/50 dark:bg-blue-950/20">
    <h4 className="text-base font-semibold text-blue-900 dark:text-blue-300 mb-1">Optimizing Thumbnails</h4>
    <p className="text-blue-800 dark:text-blue-400/80 text-sm">Always provide a high-resolution <code>thumbnailUrl</code> that matches your selected <code>aspectRatio</code>. The ambient glow effect relies on the average color values of the thumbnail image.</p>
  </div>
  <div className="p-5 rounded-xl border border-amber-200 dark:border-amber-900/50 bg-amber-50/50 dark:bg-amber-950/20">
    <h4 className="text-base font-semibold text-amber-900 dark:text-amber-300 mb-1">Autoplay Considerations</h4>
    <p className="text-amber-800 dark:text-amber-400/80 text-sm">When embedding YouTube or Vimeo videos via <code>videoUrl</code>, append <code>?autoplay=1</code> to the URL so that the video starts playing instantly when the user clicks to open the modal.</p>
  </div>
</div>

# Hero Video Player

An embeddable, hardware-accelerated video preview component designed for landing pages and high-conversion hero sections. Features a glassmorphism CTA button, automatic dark/light mode responsiveness, and full keyboard accessibility.

---

## Interactive Showcase

Use the interactive control panel below to experiment with aspect ratios, modal dimensions, and ambient glow effects in real time.

<HeroVideoPlayerShowcase />

---

## Installation

### Dependencies

This component requires **Framer Motion** for modal animations and **Lucide React** for UI icons.

```bash
npm install framer-motion lucide-react
```

### Copy the Component

Copy the core engine code directly from the Component tab in the Interactive Showcase above and place it inside components/custom/blocks/HeroVideoPlayerBlock.tsx.

## Usage Architecture

The `<HeroVideoPlayer>` adapts seamlessly across screen sizes and supports standard embed URLs from YouTube, Vimeo, or direct HTML5 video sources.

```tsx
import { HeroVideoPlayer } from "@/components/custom/blocks/HeroVideoPlayerBlock";

export default function HeroSection() {
  return (
    <section className="relative max-w-6xl mx-auto py-20 px-6">
      <div className="text-center max-w-3xl mx-auto mb-12">
        <h1 className="text-4xl sm:text-6xl font-extrabold tracking-tight mb-4">
          The Future of Web Interfaces
        </h1>
        <p className="text-lg text-zinc-600 dark:text-zinc-400">
          Deploy high-performance digital experiences in seconds with our
          unified design architecture.
        </p>
      </div>

      <HeroVideoPlayer
        aspectRatio="16/9"
        badge="Watch Product Tour"
        enableGlow="{true}"
        modalSize="lg"
        playButtonLabel="Watch 4K Demo"
        subtitle="See how teams around the world use our platform to ship UI components 10x faster."
        thumbnailUrl="[https://images.unsplash.com/photo-1618005182384-a83a8bd57fbe?auto=format&fit=crop&w=1920&q=80](https://images.unsplash.com/photo-1618005182384-a83a8bd57fbe?auto=format&fit=crop&w=1920&q=80)"
        title="Experience the Workflow in Under 3 Minutes"
        videoUrl="[https://www.youtube.com/embed/dQw4w9WgXcQ?autoplay=1](https://www.youtube.com/embed/dQw4w9WgXcQ?autoplay=1)"
      />
    </section>
  );
}
```

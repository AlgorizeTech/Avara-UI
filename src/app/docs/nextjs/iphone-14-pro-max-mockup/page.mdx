# iPhone 14 Pro Max Mockup

A sleek, responsive iPhone 14 Pro Max mockup component for Next.js applications to showcase mobile designs, images, and videos.

It provides an accurate iPhone 14 Pro Max frame with the dynamic island, supporting custom children, image sources, and video auto-playback.

## Installation

### 1. Copy the Component

You can copy the full component code directly from the Component tab in the Interactive Showcase above. Place it in `components/custom/blocks/Iphone14ProMaxMockupBlock.tsx`.

## Usage

Simply drop the component into your page. You can customize the content by passing an image source, video source, or any React children. To support both light and dark modes, pass two images inside the component.

```tsx
import { Iphone14ProMaxMockup } from "@/components/custom/blocks/Iphone14ProMaxMockupBlock";

export default function AppShowcasePage() {
  return (
    <div className="flex flex-col items-center p-4">
        {/* Support both light and dark mode images */}
        <Iphone14ProMaxMockup>
            <img 
              src="/assets/mockups/dashboard_light.png" 
              alt="Light Dashboard" 
              className="dark:hidden w-full h-full object-cover" 
            />
            <img 
              src="/assets/mockups/dashboard_dark.png" 
              alt="Dark Dashboard" 
              className="hidden dark:block w-full h-full object-cover" 
            />
        </Iphone14ProMaxMockup>
    </div>
  );
}
```

# Scroll Stack

A modern landing page section layout where cards stack on top of each other as the user scrolls, creating a feeling of 3D depth and progression.

Instead of relying on heavy event listeners and state management, this engine utilizes `framer-motion`'s `useScroll` hook natively linked to `useTransform`. This guarantees 60fps animations because the scale and opacity transformations are calculated on the main thread parallel to the native CSS `sticky` positioning.

## Interactive Showcase

Use the control panel below to tweak the math. You can adjust the **Depth Scale** (how fast the background layers shrink) and the **Card Gap** (the visual top-padding between cards in the deck).

## Installation

### Dependencies

This layout block relies on **Framer Motion** for its scroll-linked mathematics and transformations.

```bash
npm install framer-motion
```

### Copy the Component

You can copy the full engine code directly from the Component tab in the Interactive Showcase above. Place it in components/custom/blocks/ScrollStackBlock.tsx.

## Usage

Create an array of StackItem objects and pass it to the component. The container will automatically adapt its height to guarantee each card gets exactly one 100vh duration of scroll time before the next card overlaps it.

```tsx
import { ScrollStack } from "@/components/custom/blocks/ScrollStackBlock";
import { Zap, Layers } from "lucide-react";

export default function FeaturesPage() {
  const cards = [
    {
      id: "feature-1",
      title: "Lightning Fast",
      description: "Everything runs on the edge.",
      icon: Zap,
      color: "bg-indigo-600",
      content: <div>Custom visual goes here</div>, // Optional ReactNode
    },
    {
      id: "feature-2",
      title: "Modular Core",
      description: "Swap out pieces without breaking the system.",
      icon: Layers,
      color: "bg-emerald-600",
    },
  ];

  return (
    <main className="w-full bg-black min-h-screen">
      <div className="py-24 text-center text-white">
        <h1>Our Features</h1>
      </div>

      <ScrollStack
        items={cards}
        depthScale={0.05} // Cards shrink by 5% per layer
        cardGap={24} // Spacing between the top edges
      />
    </main>
  );
}
```

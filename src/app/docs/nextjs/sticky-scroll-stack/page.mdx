# Sticky Scroll Stack

A high-performance narrative section designed for showcasing multi-step workflows, service offerings, or feature highlights. Pairs native CSS `position: sticky` with Framer Motion compositor hooks to eliminate scroll jank and layout thrashing.

## Interactive Showcase

Use the control panel to adjust the GPU scaling decrement, vertical deck offset, and content rendering layouts in real time.

<StickyScrollStackShowcase />

---

## Installation

### Dependencies

This component requires **Framer Motion** for its scroll-driven compositor scaling and **Lucide React** for UI icons.

```bash
npm install framer-motion lucide-react
```

### Copy the Component

Copy the core engine code directly from the Component tab in the Interactive Showcase above and place it in components/custom/blocks/StickyScrollStackBlock.tsx.

## Usage Architecture

The `<StickyScrollStack>` component acts as a responsive section container. On desktop viewports (lg:), the left headline column pins itself while the right column cards stack over one another.

```tsx
import { StickyScrollStack } from "@/components/custom/blocks/StickyScrollStackBlock";
import { Palette, Layers } from "lucide-react";

export default function ServicesSection() {
  return (
    <StickyScrollStack "UI "Visual "ui-design", <Palette Design", Identity", badge: className="w-6 h-6 text-indigo-500" enableGlow="{true}" headerButtonText="Request free audit" headerSubtitle="We emphasize user-centric design, ensuring every project prioritizes your real audience." headerTitle="We can help you with" icon: id: items="{[" scaleStep="{0.04}" stackOffsetStep="{16}" title: {/>,
          contentType: "list",
          description: "Crafting intuitive, pixel-perfect interfaces.",
          listItems: ["Landing Pages", "Mobile Apps", "Design Systems"],
          buttonText: "View UI Showcase"
        },
        {
          id: "ux-design",
          title: "UX Design",
          badge: "User Research",
          icon: <Layers className="w-6 h-6 text-purple-500"/>,
          contentType: "split",
          description: "Data-driven architecture mapping out frictionless customer journeys.",
          imageUrl: "/showcase/ux-mapping.png",
          buttonText: "Explore UX"
        }
      ]}
    />
  );
}
```

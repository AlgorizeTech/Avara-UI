# Progress Wizard

A "Typeform" style multi-step wizard featuring buttery smooth vertical slide transitions powered by GSAP, native keyboard navigation, and an interactive progress bar.

This component relies on the **Compound Component** pattern using React Context. This allows you to place the `WizardProgress` bar independently of the main `WizardContainer`, and nest complex forms inside the `WizardStep` blocks without passing deep props.

## Interactive Showcase

Use the control panel below to change the active theme color and test the vertical slide animations. You can press `Enter` on your keyboard inside the inputs to seamlessly progress to the next step.

## Installation

### Dependencies

This component leverages **GSAP** for the high-performance vertical slide and progress bar animations.

```bash
npm install gsap
```

## Copy the Component

You can copy the full engine code directly from the Component tab in the Interactive Showcase above. Place it in components/custom/blocks/WizardBlock.tsx.

## Usage

Structure your flow using the provided sub-components. The WizardContainer automatically parses its children to count the total number of WizardStep elements, ensuring your progress bar calculates correctly without manual config.

Important Note for Keyboard Navigation: Wrap your inputs and WizardNavigation in a `<form>` tag and use onSubmit to intercept the native "Enter" key press.

```tsx
import {
  Wizard,
  WizardProgress,
  WizardContainer,
  WizardStep,
  WizardTitle,
  WizardDescription,
  WizardInput,
  WizardNavigation,
} from "@/components/custom/blocks/WizardBlock";

export default function OnboardingFlow() {
  return (
    <Wizard color="indigo" onComplete={() => console.log("Done!")}>
      {/* Top sticky progress bar */}
      <WizardProgress />

      {/* Scroll-hidden container for GSAP animations */}
      <WizardContainer>
        {/* Step 1 */}
        <WizardStep index={0}>
          <WizardTitle>1. What's your project name?</WizardTitle>
          <form
            onSubmit={(e) => {
              e.preventDefault();
              // Trigger the internal nextStep function manually, or via button click simulation
              const btn = e.currentTarget.querySelector(
                'button[type="button"]',
              );
              if (btn) (btn as HTMLButtonElement).click();
            }}
          >
            <WizardInput placeholder="e.g. Acme Corp..." autoFocus />
            <WizardNavigation />
          </form>
        </WizardStep>

        {/* Step 2 */}
        <WizardStep index={1}>
          <WizardTitle>2. What framework do you use?</WizardTitle>
          <WizardDescription>
            We will tailor the documentation to match.
          </WizardDescription>
          <form onSubmit={(e) => e.preventDefault()}>
            <WizardInput placeholder="e.g. Next.js, Vite..." />
            <WizardNavigation />
          </form>
        </WizardStep>
      </WizardContainer>
    </Wizard>
  );
}
```

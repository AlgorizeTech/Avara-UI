# Magic Bento

A premium grid layout system featuring CSS masking, continuously spinning gradient borders, and a real-time mouse-tracking spotlight effect.

<MagicBentoShowcase />
This component uses **Framer Motion**'s `useMotionTemplate` and `useMotionValue`
to track pointer coordinates without triggering heavy React state re-renders,
ensuring the volumetric glows remain silky smooth.

## Installation

### Dependencies

This layout block relies on **Framer Motion** to calculate the radial gradient coordinates dynamically.

```bash
npm install framer-motion
```

### Copy the Component

You can copy the full engine code directly from the Component tab in the Interactive Showcase above. Place it in components/custom/blocks/MagicBentoBlock.tsx.

## Usage

Wrap your cards in the `<MagicBento>` grid container. You must define the CSS variables --magic-color (for the bright spotlight/border) and --magic-glow (for the soft inner background glow) on a parent wrapper to control the theme.

## Implementation

```tsx
import { MagicBento, MagicBentoCard } from "@/components/custom/blocks/MagicBentoBlock";
import { Sparkles, Zap } from "lucide-react";

export default function FeatureGrid() {
  return (
    {/* Define the tracking glow colors via CSS Variables */}
    <div style={{
      "--magic-color": "rgba(99,102,241,1)",
      "--magic-glow": "rgba(99,102,241,0.15)"
    } as React.CSSProperties}>

      <MagicBento>
        {/* Highlight activates the spinning border */}
        <MagicBentoCard className="md:col-span-2 row-span-2" highlight>
          <Sparkles className="w-8 h-8 text-indigo-500 mb-4"/>
          <h3 className="text-2xl font-bold">Front-End Architecture</h3>
          <p className="text-zinc-500 mt-2">Highly optimized Next.js environments.</p>
        </MagicBentoCard>

        {/* Standard card without spinning border */}
        <MagicBentoCard className="col-span-1">
          <Zap className="w-6 h-6 text-zinc-400 mb-4"/>
          <h3 className="font-bold">Performance</h3>
        </MagicBentoCard>
      </MagicBento>

    </div>
  );
}
```

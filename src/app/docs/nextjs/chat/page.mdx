# Chat Application

A fully interactive, encapsulated chat interface. Features include search filtering, simulated typing/replies, dynamic unread badges, auto-scrolling, and a responsive mobile drawer sidebar.

## Interactive Showcase

Use the control panel to switch between UI layouts (including standard, minimal, and glassmorphism) and select custom color themes. The generated code snippet will automatically update to reflect your choices.

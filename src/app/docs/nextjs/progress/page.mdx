# Progress

A flexible, smoothly animated progress indicator built to handle loading states, storage meters, or step-by-step wizards.

This block is split into two composable pieces: the core `<Progress />` bar for the visual fill, and the optional `<ProgressField />` wrapper which automatically handles the layout for labels and percentage text.

## Installation

### Copy the Component

This component handles its own internal transition math and relies purely on standard Tailwind utilities.

You can copy the full engine code directly from the **Component** tab in the Interactive Showcase above. Place it in `components/custom/blocks/ProgressBlock.tsx`.

## Usage

Use the `<Progress />` component on its own for a simple visual bar, or wrap it in `<ProgressField>` to automatically align labels and values.

```tsx
import { useState } from "react";
import {
  Progress,
  ProgressField,
} from "@/components/custom/blocks/ProgressBlock";

export default function StorageWidget() {
  const [usedSpace, setUsedSpace] = useState(45); // e.g. 45GB out of 100GB

  return (
    <div className="w-full max-w-sm p-6 border border-zinc-200 dark:border-zinc-800 rounded-2xl">
      <ProgressField
        label="Storage Usage"
        value={usedSpace}
        max={100}
        valueFormat={(val, max) => `${val} GB / ${max} GB`}
      >
        <Progress
          value={usedSpace}
          max={100}
          variant="glow"
          color="#10b981"
          barSize="md"
        />
      </ProgressField>
    </div>
  );
}
```

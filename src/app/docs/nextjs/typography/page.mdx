# Typography

Styles for headings, paragraphs, lists, and inline text elements.

While Tailwind provides fantastic utility classes for text, manually copying strings like `scroll-m-20 text-4xl font-extrabold tracking-tight` onto every single `<h1>` tag in your application is tedious and error-prone. The `TypographyBlock` provides a collection of semantic React components that standardize your vertical rhythm, sizing, and dark-mode colors across your entire project.

## Installation

### Copy the Component

This suite of components simply wraps native HTML tags with carefully crafted Tailwind CSS strings. It is completely dependency-free.

You can copy the full engine code (in either TypeScript or JavaScript) directly from the **Component** tab in the Interactive Showcase above. Place it in `components/custom/blocks/TypographyBlock.tsx`.

---

## Usage

Simply import the semantic wrappers you need and use them exactly like standard HTML tags.

```tsx
import {
  H1,
  H2,
  P,
  Blockquote,
  List,
  InlineCode,
  Lead,
} from "@/components/custom/blocks/TypographyBlock";

export default function BlogPost() {
  return (
    <article>
      <H1>Building Next-Gen UIs</H1>
      <Lead>A deep dive into modular component architecture.</Lead>

      <P>
        When building large-scale applications, you want to avoid repeating
        yourself. This is where <InlineCode>Typography</InlineCode> components
        shine.
      </P>

      <H2>The Core Principles</H2>
      <List>
        <li>Maintain semantic HTML structure</li>
        <li>Automate vertical spacing (margins)</li>
        <li>Ensure accessible color contrast</li>
      </List>

      <Blockquote>
        Consistency is the easiest way to make your app look professional.
      </Blockquote>
    </article>
  );
}
```

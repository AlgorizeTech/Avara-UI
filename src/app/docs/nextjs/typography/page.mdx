# Typography

Styles for headings, paragraphs, lists, and inline text elements.

While Tailwind provides fantastic utility classes for text, manually copying strings like `scroll-m-20 text-4xl font-extrabold tracking-tight` onto every single `<h1>` tag in your application is tedious and error-prone. The `TypographyBlock` provides a collection of semantic React components that standardize your vertical rhythm, sizing, and dark-mode colors across your entire project.

## Examples

Every component is a thin semantic wrapper around a native HTML tag, so you compose them exactly like the tags themselves.

export const usageArticle = `import {
  Blockquote,
  H1,
  H2,
  H3,
  InlineCode,
  Large,
  Lead,
  List,
  Muted,
  P,
  Small,
} from "@/components/custom/blocks/TypographyBlock";

export default function BlogPost() {
  return (
    <article className="mx-auto max-w-2xl">
      <H1>Crafting High-Performance UI Architecture</H1>
      <Lead className="mt-4">
        A modern engineering guide to building scalable, accessible, and resilient design systems.
      </Lead>

      <P>
        Typography is the backbone of intuitive user interface design. Rather than hardcoding chaotic inline utilities like{" "}
        <InlineCode>text-4xl font-extrabold tracking-tight</InlineCode> across hundreds of files, establishing a unified typography token hierarchy brings rhythmic consistency.
      </P>

      <H2>Semantic Structure & Accessibility</H2>
      <Blockquote>
        "Design is not just what it looks like and feels like. Design is how it works." — Steve Jobs
      </Blockquote>

      <H3>Core Engineering Principles</H3>
      <List>
        <li>Automatic vertical rhythm and baseline spacing between components.</li>
        <li>Native dark mode contrast compliance with HSL color tokens.</li>
        <li>Fluid typography scaling across mobile, tablet, and desktop displays.</li>
      </List>

      <div className="mt-8 flex flex-wrap items-center justify-between gap-4 border-t pt-6">
        <Large>Written by Alex Rivers</Large>
        <div className="flex flex-col sm:items-end">
          <Small>Author Status: Principal Architect</Small>
          <Muted>Updated August 2026</Muted>
        </div>
      </div>
    </article>
  );
}`;

export const usageHeadings = `import { H1, H2, H3, H4 } from "@/components/custom/blocks/TypographyBlock";

export const usageParagraph = `import { InlineCode, Lead, P } from "@/components/custom/blocks/TypographyBlock";

export default function Body() {
  return (
    <>
      <Lead>A modern engineering guide to building scalable, accessible design systems.</Lead>
      <P>
        Typography is the backbone of intuitive user interface design. Standardized components keep the rhythm predictable — no more pasting{" "}
        <InlineCode>text-4xl font-extrabold tracking-tight</InlineCode> by hand.
      </P>
      <P>Subsequent paragraphs automatically maintain predictable top margins.</P>
    </>
  );
}`;

  <li>Fluid typography scaling across mobile, tablet, and desktop displays.</li>

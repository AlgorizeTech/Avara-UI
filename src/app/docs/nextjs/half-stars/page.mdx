# Half Stars Rating

A sleek, customizable star rating component for Next.js applications that supports exact decimal ratings (e.g., 3.7 or 4.5) through SVG clip paths. It also supports interactive mode, allowing users to hover and click to set their own rating.

It provides an accurate fractional fill, allowing you to beautifully display user reviews, product ratings, and satisfaction scores without being limited to just full or half stars.

## Installation

Ensure you have Tailwind CSS configured in your project, as the component uses standard Tailwind classes for styling.

### Copy the Component

You can copy the full component code directly from the **Component** tab in the Interactive Showcase above. Place it in `components/custom/blocks/HalfStarsBlock.tsx`.

---

## Usage

Simply drop the component into your page. You can customize the rating, size, colors, and maximum number of stars. To make it interactive, pass `interactive={true}` and provide an `onRatingChange` handler.

```tsx
"use client";

import React, { useState } from "react";
import { HalfStars } from "@/components/custom/blocks/HalfStarsBlock";

export default function AppShowcasePage() {
  const [fullRating, setFullRating] = useState(3);
  const [halfRating, setHalfRating] = useState(3.5);
  const [preciseRating, setPreciseRating] = useState(4.2);
  const [customRating, setCustomRating] = useState(7.5);

  return (
    <div className="flex flex-col gap-8 p-8">
        <div>
          <h3>Full Stars (Interactive)</h3>
          <HalfStars 
            rating={fullRating} 
            interactive={true} 
            allowHalf={false} 
            onRatingChange={setFullRating}
            showText={false}
          />
        </div>

        <div>
          <h3>Half Stars (Interactive)</h3>
          <HalfStars 
            rating={halfRating} 
            interactive={true} 
            allowHalf={true} 
            onRatingChange={setHalfRating} 
          />
        </div>

        <div>
          <h3>Continuous Fractions (Interactive)</h3>
          <HalfStars 
            rating={preciseRating} 
            interactive={true} 
            step={0.1}
            onRatingChange={setPreciseRating} 
          />
        </div>

        <div>
          <h3>Custom Max Stars (Interactive)</h3>
          <HalfStars 
            rating={customRating} 
            maxStars={10}
            activeColor="text-red-500" 
            inactiveColor="text-red-200 dark:text-red-900"
            interactive={true} 
            allowHalf={true} 
            onRatingChange={setCustomRating} 
          />
        </div>
    </div>
  );
}
```

```tsx
  maxStars?: number;
  size?: number;
  activeColor?: string;
  inactiveColor?: string;
  showText?: boolean;
  interactive?: boolean;
  allowHalf?: boolean;
  step?: number;
  onRatingChange?: (rating: number) => void;
  onHoverChange?: (rating: number) => void;
}
```

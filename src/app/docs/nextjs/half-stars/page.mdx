# Half Stars Rating

A sleek, customizable star rating component for Next.js applications that supports exact decimal ratings (e.g., 3.7 or 4.5) through SVG clip paths. It also supports interactive mode, allowing users to hover and click to set their own rating.

It provides an accurate fractional fill, allowing you to beautifully display user reviews, product ratings, and satisfaction scores without being limited to just full or half stars.

## Best Practices & Guidelines

<div className="flex flex-col gap-4 my-6 not-prose">
  <div className="p-5 rounded-xl border border-blue-200 dark:border-blue-900/50 bg-blue-50/50 dark:bg-blue-950/20">
    <h4 className="text-base font-semibold text-blue-900 dark:text-blue-300 mb-1">Precision Steps</h4>
    <p className="text-blue-800 dark:text-blue-400/80 text-sm">If you are allowing user input via <code>interactive={true}</code>, it is recommended to set <code>allowHalf={true}</code> (step 0.5) or <code>step={1}</code> for standard reviews. Setting <code>step={0.1}</code> can make it difficult for users to intentionally click a precise score like 4.0 exactly.</p>
  </div>
  <div className="p-5 rounded-xl border border-amber-200 dark:border-amber-900/50 bg-amber-50/50 dark:bg-amber-950/20">
    <h4 className="text-base font-semibold text-amber-900 dark:text-amber-300 mb-1">Color Contrast</h4>
    <p className="text-amber-800 dark:text-amber-400/80 text-sm">Ensure your <code>inactiveColor</code> provides enough contrast against your background so users can clearly see the empty stars. By default, <code>text-slate-200</code> works well on white backgrounds.</p>
  </div>
</div>

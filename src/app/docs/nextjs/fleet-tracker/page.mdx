# Fleet Tracker

An interactive, responsive fleet management dashboard featuring a synchronized sidebar and live map integration using React Leaflet.

## Interactive Preview

Click on any vehicle in the sidebar to fly the map to its location, or click a map marker to highlight it in the sidebar. You can also filter vehicles dynamically using the search bar.

## Installation

1. Install Dependencies
   You must install leaflet and react-leaflet for the map component to function.

```Bash
npm install leaflet react-leaflet
npm install -D @types/leaflet
```

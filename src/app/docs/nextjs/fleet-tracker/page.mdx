# Fleet Tracker

An interactive, responsive fleet management dashboard featuring a synchronized sidebar and live map integration using React Leaflet.

## Interactive Showcase

Explore the different architectural variants of the fleet tracker. Switch between the classic split-view (`default`), a floating panel over a light map (`minimal`), or a stunning backdrop-blurred panel over a dark map (`glass`).

Click on any vehicle in the sidebar to fly the map to its location, or click a map marker to highlight it in the sidebar. Map markers and UI accents automatically adapt to the selected Theme Color.

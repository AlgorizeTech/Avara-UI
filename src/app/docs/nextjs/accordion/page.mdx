# Accordion

A reusable accordion with collapsible content sections, dynamic icons, and highly customizable styling variants.

## Interactive Showcase

Explore the different structural variants of the accordion component. Toggle between interaction modes (like forcing one panel to always remain open), and switch styling variants to automatically generate the correct integration code.

<AccordionShowcase />

## Installation

1. This component relies on `shadcn/ui` base primitives. Install them first:

````bash
npx shadcn-ui@latest add accordion
```

## Install the required icon library:

Create the Accordion.tsx component inside your project and paste the generated code.

```bash
npm install lucide-react
````

## Custom Styling Override Example

You can completely override the styles of the triggers, content, and the expand icon to match your brand by utilizing the extensive ClassName props.

```
"use client";

import { Accordion } from "@/components/custom/blocks/Accordion";

export default function CustomStylingDemo() {
  return (
    <Accordion
      accordionData={data}
      defaultValue="mobile"
      className="border-2 border-emerald-200 dark:border-emerald-800 rounded-xl"
      itemClassName="border-b border-gray-100 dark:border-gray-800 last:border-b-0"
      triggerClassName="hover:bg-emerald-50 dark:hover:bg-emerald-900/30 text-emerald-900 dark:text-emerald-100 font-medium"
      contentClassName="bg-emerald-50/50 dark:bg-emerald-900/20 text-emerald-800 dark:text-emerald-200"
      expandIcon="ArrowDown"
      expandIconClassName="[&[data-state=open]>svg]:rotate-180"
    />
  );
}
```

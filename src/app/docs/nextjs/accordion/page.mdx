# Accordion

A reusable accordion with collapsible content sections, icons, and highly customizable styling variants.

## Basic Accordion

A simple, standard accordion. By default, it allows only one item to be open at a time (`type="single"`).

## Preview

<div className="w-full max-w-2xl mx-auto my-8 p-6 border border-zinc-200 dark:border-zinc-800 rounded-xl overflow-hidden shadow-sm bg-white dark:bg-gray-950">
  <Accordion
    accordionData={faqData}
    defaultValue="getting-started"
  />
</div>

## Code

```tsx
"use client";

import { HelpCircle, CreditCard, Shield } from "lucide-react";
import { Accordion } from "@/components/custom/accordion";

export default function BasicAccordionDemo() {
  const faqData = [
    {
      value: "getting-started",
      title: "How do I get started?",
      icon: <HelpCircle className="w-4 h-4" />,
      content: ["Getting started is easy! Simply sign up and follow our onboarding.", "We'll guide you through setting up your profile."],
    },
    {
      value: "pricing",
      title: "What are your pricing plans?",
      icon: <CreditCard className="w-4 h-4" />,
      content: ["We offer flexible pricing plans.", "Basic plan starts at $9/month."],
    }
  ];

  return (
    <Accordion
      accordionData={faqData}
      defaultValue="getting-started"
    />
  );
}
```
## Multiple Selection & Variants
Set type="multiple" to allow multiple sections to be open simultaneously. You can also use built-in variants like bordered, filled, or ghost.

```tsx

    <Accordion
      accordionData={technicalData}
      defaultValue="mobile"
      className="border-2 border-emerald-200 dark:border-emerald-800 rounded-xl"
      itemClassName="border-b border-gray-100 dark:border-gray-800 last:border-b-0"
      triggerClassName="hover:bg-emerald-50 dark:hover:bg-emerald-900/30 text-emerald-900 dark:text-emerald-100 font-medium"
      contentClassName="bg-emerald-50/50 dark:bg-emerald-900/20 text-emerald-800 dark:text-emerald-200"

```

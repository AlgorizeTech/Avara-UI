# Advanced Hero Section

A highly composable, multi-layout Hero component perfect for landing pages, complete with advanced UI effects like glitch text and glowing borders.

Building a flexible hero section is notoriously annoying because the DOM layout changes drastically depending on the design (e.g., centering the text vs placing an image beside it). This `HeroBlock` separates layout structure from visual style through **Compound Components**. You write the exact same clean component structure every time, and simply change the `layout` and `variant` props to automatically orchestrate the DOM.

## Installation

### Copy the Component

This component handles all layout shifts via Tailwind grid utilities. The glitch effects and glow animations use injected, dependency-free CSS keyframes.

You can copy the full engine code directly from the **Component** tab in the Interactive Showcase above. Place it in `components/custom/blocks/HeroBlock.tsx`.

## Usage

Structure your Hero section using the provided sub-components. The parent `<Hero>` container dictates the layout, while the children dictate the content.

```tsx
import {
  Hero,
  HeroContent,
  HeroBadge,
  HeroTitle,
  HeroDescription,
  HeroActions,
  HeroAction,
  HeroVisual,
} from "@/components/custom/blocks/HeroBlock";
import { ArrowRight, Sparkles } from "lucide-react";

export default function MarketingHeader() {
  return (
    <Hero color="#10b981" layout="split-right" variant="glow">
      <HeroContent>
        <HeroBadge>
          <Sparkles className="w-4 h-4" />
          <span>New Feature Released</span>
        </HeroBadge>

        <HeroTitle glitch>Ship products faster than ever before.</HeroTitle>

        <HeroDescription>
          Stop rebuilding the same foundational components. Drop in our
          high-performance UI kit and focus on your business logic.
        </HeroDescription>

        <HeroActions>
          <HeroAction variant="glow">
            Get Started <ArrowRight className="w-4 h-4" />
          </HeroAction>
          <HeroAction variant="outline">Read Docs</HeroAction>
        </HeroActions>
      </HeroContent>

      <HeroVisual>
        <img
          src="/dashboard-preview.png"
          alt="Dashboard Screenshot"
          className="w-full h-full object-cover rounded-3xl border border-zinc-800"
        />
      </HeroVisual>
    </Hero>
  );
}
```

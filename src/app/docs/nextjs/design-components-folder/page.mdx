## Installation

### Copy the Component

Save the full Hub in your project at `src/components/custom/blocks/DesignComponentsFolder.tsx` or the standalone Box at `src/components/custom/blocks/DesignFolderBox.tsx`.

### Dependencies

Ensure you have `framer-motion` (or `motion`), `lucide-react`, and `@/lib/utils` installed in your Next.js project.

```bash
npm install motion lucide-react
```

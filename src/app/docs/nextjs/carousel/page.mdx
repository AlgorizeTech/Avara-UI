# Carousel

A collection of customizable and interactive carousel components for image galleries, hero sections, and fluid presentations.

## Interactive Showcase

Explore the different variants of the carousel component. Switch between standard image sliders, full-width hero banners, positionable thumbnails, and GSAP-powered fluid glass sliders.

Use the control panel below to switch variants and automatically generate the integration code.

<CarouselShowcase />

## Installation

1. Create the `carousel.tsx` and `FluidGlassSlider.tsx` components inside your project.
2. Install the required dependencies:

```bash
npm install lucide-react gsap
```

# Email Dashboard

A premium, fully interactive email client featuring a modern SaaS aesthetic, unread/read states, folder management, dynamic labels, and a rich compose modal.

## Interactive Showcase

This component is fully encapsulated. Use the control panel to switch between UI layouts (including minimal and glassmorphism) and select custom color themes.

Try filtering by folders, starring an email, or opening the Compose modal to see the glassmorphism effects applied to absolute overlays.

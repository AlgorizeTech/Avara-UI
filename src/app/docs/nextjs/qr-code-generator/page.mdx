# QR Code Generator

A premium, customizable QR code generator component built specifically for Next.js applications.

It includes distinct customization options (Colors, Logos, and Sizes) to match different areas of your application. It safely handles React rendering to generate high-quality QR codes on the fly.

Use the control panel below to test the different styles and configurations for your QR codes!

## Installation

### 1. Install Dependencies

This component relies on `qrcode.react` to generate the QR codes easily and securely.

```bash
npm install qrcode.react
```

### 2. Copy the Component

You can copy the full engine code directly from the Component tab in the Interactive Showcase above. Place it in components/custom/blocks/QrCodeGeneratorBlock.tsx.

## Usage

Simply drop the component into your page. You can customize the layout by passing the necessary props.

```tsx
import { QrCodeGenerator } from "@/components/custom/blocks/QrCodeGeneratorBlock";

export default function DashboardPage() {
  return (
    <div className="flex flex-col items-center p-4">
        {/* Display a QR code with custom value */}
        <QrCodeGenerator value="https://algorizetech.com" size={256} />
    </div>
  );
}
```

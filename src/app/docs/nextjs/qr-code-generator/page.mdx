# QR Code Suite

A premium, dual-purpose QR Code component suite built for Next.js applications. 

Whether you need to generate high-fidelity, customizable QR codes (with PNG/PDF download support) or allow users to upload and scan QR code images to extract embedded URLs, this suite has you covered.

## Installation

### 1. Install Dependencies

<div id="generator-docs-install">

The QR Code Generator relies on the lightweight, industry-standard package `qrcode.react` for generating SVG QR Codes.

```bash
npm install qrcode.react
```

</div>

<div id="reader-docs-install">

The QR Code Reader relies on the `jsqr` package for reading and extracting data from uploaded images, and `lucide-react` for the UI icons.

```bash
npm install jsqr lucide-react
```

</div>

## Usage

<div id="generator-docs-usage">

Generate standard QR codes with custom sizes, colors, and correction levels.

```tsx
import { QrCodeGenerator } from "@/components/custom/blocks/QrCodeGeneratorBlock";

export default function GeneratorExample() {
  return (
    <div className="flex gap-4 items-center p-8">
      <QrCodeGenerator value="https://algorizetech.com" size={200} />
      <QrCodeGenerator value="Scan Me!" size={150} fgColor="#3b82f6" />
    </div>
  );
}
```

</div>

<div id="reader-docs-usage">

Allow users to click or drag-and-drop a QR code image to read its contents.

```tsx
import { QrCodeReader } from "@/components/custom/blocks/QrCodeReaderBlock";

export default function ReaderExample() {
  return (
    <div className="p-8">
      <QrCodeReader onRead={(data) => console.log("Scanned QR:", data)} />
    </div>
  );
}
```

</div>

## Best Practices & Guidelines

<div id="generator-docs-best-practices">
<div className="flex flex-col gap-4 my-6 not-prose">
  <div className="p-5 rounded-xl border border-indigo-200 dark:border-indigo-900/50 bg-indigo-50/50 dark:bg-indigo-950/20">
    <h4 className="text-base font-semibold text-indigo-900 dark:text-indigo-300 mb-1">Color Contrast</h4>
    <p className="text-indigo-800 dark:text-indigo-400/80 text-sm">Ensure a high contrast between the background and foreground colors. A light background (e.g., <code>#FFFFFF</code>) with a dark foreground (e.g., <code>#000000</code>) is recommended for optimal scannability by smartphone cameras.</p>
  </div>
  <div className="p-5 rounded-xl border border-emerald-200 dark:border-emerald-900/50 bg-emerald-50/50 dark:bg-emerald-950/20">
    <h4 className="text-base font-semibold text-emerald-900 dark:text-emerald-300 mb-1">Error Correction Level</h4>
    <p className="text-emerald-800 dark:text-emerald-400/80 text-sm">Use <strong>L (Low)</strong> for simple URLs to keep the QR code visually clean and sparse. Use <strong>H (High)</strong> if you plan to overlay a custom logo in the center, as it allows up to 30% of the code to be obscured without breaking.</p>
  </div>
</div>
</div>

<div id="reader-docs-best-practices">
<div className="flex flex-col gap-4 my-6 not-prose">

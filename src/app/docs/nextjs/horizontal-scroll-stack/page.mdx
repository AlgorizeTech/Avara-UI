# Horizontal Scroll Stack

A high-performance interactive scroll experience inspired by modern agency design patterns. As the user scrolls vertically down the page, a sticky container pins to the viewport and translates your card items horizontally across the screen in sync with the scroll progress.

---

## Installation

### Dependencies

This component uses **Framer Motion** for high-performance scroll tracking and layout transformations.

```bash
npm install framer-motion lucide-react
```

### Copy the Component

Copy the core engine code directly from the Component tab in the Interactive Showcase above and place it inside components/custom/blocks/HorizontalScrollStackBlock.tsx.

## Usage Architecture

The `<HorizontalScrollStack>` requires an array of step items. Each item can contain a custom title, description, badge number, and icon.

```tsx
import { HorizontalScrollStack } from "@/components/custom/blocks/HorizontalScrollStackBlock";
import { Compass, FileText, Sparkles, Layers } from "lucide-react";

export default function ProcessSection() {
  const steps = [
    {
      id: "1",
      title: "Understand",
      description: "Business goals and strategies, persona and painpoints.",
      icon: <Compass />,
    },
    {
      id: "2",
      title: "Define",
      description: "Strategy, information architecture, user flows.",
      icon: <FileText />,
    },
    {
      id: "3",
      title: "Ideate",
      description: "Brainstorming, solution propose, sketching.",
      icon: <Sparkles />,
    },
    {
      id: "4",
      title: "Design",
      description: "Style guide, design system, interface design.",
      icon: <Layers />,
    },
  ];

  return (
    <HorizontalScrollStack
      items="{steps}"
      subtitle="from understanding your goals to delivering polished assets."
      title="We follow a streamlined design process"
    />
  );
}
```

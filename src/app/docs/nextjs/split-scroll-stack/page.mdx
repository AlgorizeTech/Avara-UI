# Split-ScrollStack

A high-impact, scroll-driven landing page layout engineered exclusively with **GSAP's ScrollTrigger plugin**. As users scroll down through a narrative sequence of feature sections on one side, the opposite column maintains a sticky container that dynamically stacks custom visual cards into a 3D deck.

Whenever a new section enters the viewport, GreenSock slides the matching card up from below while calculating a depth transform (`scale` and `translateY`) to push previous cards further back into the stack.

## Installation

### Dependencies

This component relies exclusively on **GSAP** and its native `ScrollTrigger` plugin for all viewport detection and 3D card scaling math.

```bash
npm install gsap lucide-react
```

### Copy the Component

Copy the core engine code directly from the Component tab in the Interactive Showcase above and place it in components/custom/blocks/SplitScrollStackBlock.tsx.

## Usage Architecture

The `<SplitScrollStack>` component automatically configures responsive grid heights and sticky positioning. You simply provide an array of objects containing your text sequence and custom visual JSX payloads for the stacked cards.

```tsx
import { SplitScrollStack } from "@/components/custom/blocks/SplitScrollStackBlock";

export default function LandingSection() {
  const items = [
    {
      id: "landing",
      stepNumber: "01",
      title: "Landing Page Design",
      description: "We engineer high-converting layouts with scroll-triggered GSAP animations.",
      tags: ["Conversion Focused", "Figma To Code"],
      cardContent: <div className="p-6 bg-amber-500/10">Custom Visual 1</div>,
    },
    {
      id: "saas",
      stepNumber: "02",
      title: "SaaS Development",
      description: "Modular, multi-tenant web applications designed to scale to millions of requests.",
      tags: ["Multi-Tenant Architecture", "Real-Time Sync"],
      cardContent: <div className="p-6 bg-indigo-500/10">Custom Visual 2</div>,
    },
  ];

  return (
    <div className="max-w-7xl mx-auto py-20 px-6">
      <SplitScrollStack "left" // Easily cardDepthScale="{0.05}" cardOffset="{16}" color="#FFAB1D" items="{items}" stickySide="right" switch to/>
    </div>
  );
}
```

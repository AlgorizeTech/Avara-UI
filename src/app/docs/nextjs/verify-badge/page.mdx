# Verify Badge

A versatile verified badge component that can be customized with various styles (blue, gold, dark, gray), sizes, and an optional subtle pulse animation for premium aesthetics.

It includes distinct customization options to match different areas of your application.


## Best Practices & Guidelines

<div className="flex flex-col gap-4 my-6 not-prose">
  <div className="p-5 rounded-xl border border-blue-200 dark:border-blue-900/50 bg-blue-50/50 dark:bg-blue-950/20">
    <h4 className="text-base font-semibold text-blue-900 dark:text-blue-300 mb-1">Accessibility First</h4>
    <p className="text-blue-800 dark:text-blue-400/80 text-sm">Always ensure that you add an <code>aria-label</code> or <code>title</code> to the badge so that screen readers can convey the "Verified" status to visually impaired users.</p>
  </div>
  <div className="p-5 rounded-xl border border-amber-200 dark:border-amber-900/50 bg-amber-50/50 dark:bg-amber-950/20">

    <p className="text-amber-800 dark:text-amber-400/80 text-sm">Use the <code>sm</code> or <code>md</code> sizes when placing the badge directly next to standard text (like usernames). The <code>lg</code> and <code>xl</code> sizes are best reserved for profile headers or prominent display cards.</p>
  </div>
</div>

# Verify Badge

A versatile verified badge component that can be customized with various styles (blue, gold, dark, gray), sizes, and an optional subtle pulse animation for premium aesthetics.

It includes distinct customization options to match different areas of your application.

## Interactive Showcase

Use the control panel below to test the different styles and configurations for your verify badge!

## Installation

### 1. Install Dependencies

This component uses `lucide-react` for the checkmark icon and standard Tailwind utilities.

```bash
npm install lucide-react clsx tailwind-merge
```

### 2. Copy the Component

You can copy the full engine code directly from the Component tab in the Interactive Showcase above. Place it in `components/custom/blocks/VerifyBadgeBlock.tsx`.

## Usage

Simply drop the component into your page. You can customize the layout by passing the necessary props.

```tsx
import { VerifyBadge } from "@/components/custom/blocks/VerifyBadgeBlock";

export default function ProfilePage() {
  return (
    <div className="flex items-center gap-2">
      <span className="font-semibold text-lg">AlgorizeTech</span>
      {/* Display a verified badge */}
      <VerifyBadge variant="blue" size="lg" animate={true} />
    </div>
  );
}
```

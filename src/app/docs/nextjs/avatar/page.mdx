# Avatar

A reusable avatar component with built-in support for single avatars, grouped avatar stacks, varying sizes, and dynamic online/offline status indicators.

## Interactive Showcase

Explore the different variations of the Avatar component. Toggle between single and grouped users, adjust the sizing, and test the different activity status indicators. The code snippet will automatically update based on your selections.

<AvatarShowcase />

## Installation

1. Create the `Avatar.tsx` component inside your project.
2. Install the required dependencies (relies on `shadcn/ui` base components):

```bash
npx shadcn-ui@latest add avatar
```

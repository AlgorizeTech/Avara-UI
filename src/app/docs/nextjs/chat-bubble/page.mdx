# Animated Chat Bubble

A complete, GSAP-powered compound component system for building highly customized chat interfaces, messengers, and support widgets.

Building a polished chat interface requires handling complex edge cases: **message grouping** (dynamically adjusting border radiuses so stacked messages look connected), **typing indicators**, **read receipts**, and smooth entrance animations. This component abstracts all of that logic using React Context and high-performance GSAP animations.

## Installation

### Dependencies

This component relies on **GSAP** for the high-performance entrance and typing indicator animations, and **Lucide React** for the read receipt ticks.

```bash
npm install gsap lucide-react
```

### Copy the Component

You can copy the full engine code directly from the Component tab in the Interactive Showcase above. Place it in components/custom/blocks/ChatBubbleBlock.tsx.

## Usage Architecture

Structure your chat messages using the provided sub-components. The parent `<ChatBubble />` container dictates the variant (sent vs. received) and the layout grouping, which automatically propagates to the child components to handle border radiuses and layout alignment.

```tsx
import {
  ChatBubble,
  ChatAvatar,
  ChatMessage,
  ChatTimestamp,
  ChatTypingIndicator,
} from "@/components/custom/blocks/ChatBubbleBlock";

export default function ChatInterface() {
  return (
    <div className="flex flex-col gap-1.5 p-4 max-w-md mx-auto">
      {/* Grouped Received Messages */}
      <ChatBubble layout="group-top" variant="received">
        <ChatAvatar fallback="AI" src="/bot-avatar.png" />
        <ChatMessage>Hello! How can I help you today?</ChatMessage>
      </ChatBubble>

      <ChatBubble layout="group-bottom" variant="received">
        <ChatAvatar fallback="AI" />
        <ChatMessage>
          I can answer questions, process data, or generate code.
          <ChatTimestamp time="10:24 AM" />
        </ChatMessage>
      </ChatBubble>

      <div className="h-2" />

      {/* Single Sent Message with Read Receipt */}
      <ChatBubble layout="default" variant="sent">
        <ChatAvatar fallback="ME" />
        <ChatMessage color="blue">
          Can you show me how to use the ChatBubble component?
          <ChatTimestamp status="read" time="10:25 AM" />
        </ChatMessage>
      </ChatBubble>

      <div className="h-2" />

      {/* Animated Typing Indicator */}
      <ChatBubble variant="received">
        <ChatAvatar fallback="AI" />
        <ChatTypingIndicator />
      </ChatBubble>
    </div>
  );
}
```

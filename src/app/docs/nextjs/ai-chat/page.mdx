# AI Assistant Chat

A premium, interactive LLM chat interface featuring conversation history management, real-time typing indicators, editable chat titles, and a modern glassmorphism prompt bar.

## Interactive Preview

Try sending a prompt to the AI, or click the "New Chat" button to start a fresh conversation thread. You can also rename or delete previous chats in the sidebar.

## Code

```tsx
"use client";

import AIChat from '@/components/ui/ai-chat';

export default function AIChatDemo() {
  const chatHistory = [
    { id: 1, title: "Help with React Components", date: "Today" },
    { id: 2, title: "Write a python script for SEO", date: "Today" },
    { id: 3, title: "Ideas for marketing campaign", date: "Yesterday" }
  ];

  const initialMessages = [
    {
      id: 1,
      role: "ai",
      content: "Hello! I am your AI assistant. How can I help you today?",
      time: "10:00 AM",
    }
  ];

  return (
    <div className="w-full">
      <AIChat chatHistory={chatHistory} initialMessages={initialMessages} />
    </div>
  );
}

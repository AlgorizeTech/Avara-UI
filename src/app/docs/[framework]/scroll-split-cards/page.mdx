# Scroll Split Cards

A cinematic scroll-driven storytelling component featuring a unified panoramic landscape that splits into three distinct physical card panels upon scrolling. As the user continues downward, the cards separate, execute a perspective-rich 180° 3D flip to reveal curated editorial narratives, and finally float upward away from the viewport.

`ScrollSplitCards` brings tactile visual immersion to brand origin stories, architectural journeys, editorial photography features, and landmark case studies.

## Props Reference

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `imageUrl` | `string` | Golden Gate Bridge | Panoramic image URL sliced across the 3 card faces. |
| `imageAlt` | `string` | `"Panoramic landscape..."` | Accessibility alt text for image panels. |
| `headerTitle` | `string` | `"Scroll"` | Main title displayed at the top of the sticky view. |
| `headerSubtitle` | `string` | `"Scroll to see it change"` | Secondary instructional subtitle. |
| `cards` | `SplitCardItem[]` | Default 3 cards | Array of card data containing `number`, `tag`, `title`, `description`, and colors. |
| `containerHeight` | `string` | `"720px"` | Height of the presentation stage. Defaults to a self-contained 720px. |
| `enableScrollIndicator` | `boolean` | `true` | Shows or hides the minimalist animated mouse pill indicator. |

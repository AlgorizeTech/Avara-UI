## Features
Single or multiple open panels, a one-time stack entrance, and nine variants that all read your theme tokens.

<div className="grid grid-cols-1 sm:grid-cols-2 gap-4 my-6 not-prose">
  <InfoCard title="Follows your theme">
    <p>Every variant is built from the shadcn tokens, so changing <code>--primary</code> restyles the open panel, the rail and the icon tile together.</p>
  </InfoCard>
  <InfoCard title="Accessible">
    <p>Radix handles roles, arrow-key navigation and focus. The visible focus ring follows the shape of each variant, and the entrance respects reduced motion.</p>
  </InfoCard>
  <InfoCard title="Responsive">
    <p>Rows wrap cleanly at phone width; the open card in the default variant only grows wider than the list from <code>sm</code> up.</p>
  </InfoCard>
  <InfoCard title="No animation library">
    <p>The <code>soft</code>, <code>tray</code>, <code>inset</code> and <code>bracket</code> variants open and close with CSS keyframes that ship inside the component. The stack entrance uses the Web Animations API. The only dependency beyond Radix is <code>lucide-react</code>.</p>
  </InfoCard>
</div>

## Best Practices & Guidelines

<div className="flex flex-col gap-4 my-6 not-prose">
  <InfoCard title="Usage Guidelines">
    <p>Use <code>animation="stack"</code> once per page, on the accordion you want people to notice; two decks dealing at the same time cancel each other out. Give it at least three items so the pile reads as a deck, and keep <code>defaultValue</code> set so the open card is part of the deal.</p>
  </InfoCard>

## About Shadcn Accordion

**What it is.** A copy-paste accordion for React, built on the Radix UI primitive and styled with shadcn theme tokens. You pass an array of items and it renders the icons, titles and panels.

**When to use it.** FAQ sections, settings panels, onboarding checklists and help centers. Pick a list style to match the surface it sits on, or the brand reveal to show clients and partners.

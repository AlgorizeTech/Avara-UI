# Creating Your First App

Two guides in one. The first gets an Algorize UI component rendering in a few
minutes; the rest is a Next.js walkthrough for anyone starting from scratch.

## Prerequisites

Before you start, make sure you have:

- Node.js 18.17 or later installed
- A code editor (we recommend Visual Studio Code)
- A terminal or command prompt

## Quick start: your first component

### 1. Create a Next.js app

Skip this if you already have one.

```bash
npx create-next-app@latest my-app --typescript --tailwind --app
cd my-app
```

### 2. Initialize shadcn

Run once per project. It writes `components.json` and the `cn` helper in
`lib/utils.ts` that every component imports.

<Cli command={`init`} />

### 3. Add a component

Every component page carries its own command — this one installs the card:

<Cli command={`add card.json`} />

The CLI writes `components/custom/blocks/CardBlock.tsx` and installs whatever
that component needs.

### 4. Use it

```tsx
// app/page.tsx
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/custom/blocks/CardBlock";

export default function Home() {
  return (
    <main className="p-24">
      <Card variant="bordered" className="w-full max-w-sm">
        <CardHeader>
          <CardTitle>Welcome</CardTitle>
          <CardDescription>Your first Algorize UI component.</CardDescription>
        </CardHeader>
        <CardContent>
          <p className="text-sm">
            Edit the file the CLI just wrote — it is yours now.
          </p>
        </CardContent>
      </Card>
    </main>
  );
}
```

Run `npm run dev` and it is on screen. Every component page has a **Usage** tab
with a full file you can paste the same way.

## Full walkthrough: Next.js from scratch

Everything below is independent of the quick start above and does not use
Algorize UI. It builds a small Next.js app from an empty directory — start here
if you are new to Next.js, or skip it entirely if you already have an app
running.

### Step 1: Create a New Next.js App

Open your terminal and run the following command:

```bash
npx create-next-app@latest my-first-app --typescript --app
```

This command creates a new Next.js application with:

- TypeScript support
- The App Router (recommended for new projects)
- A basic project structure

Navigate to your new project directory:

```bash
cd my-first-app
```

### Step 2: Run the Development Server

Start the development server:

```bash
npm run dev
```

Visit `http://localhost:3000` in your browser to see your new Next.js app!

### Step 3: Explore the Project Structure

Your new Next.js app has the following structure:

```bash
my-first-app/
├── app/
│   ├── layout.tsx
│   └── page.tsx
├── public/
│   └── next.svg
├── styles/
│   └── globals.css
├── next.config.mjs
├── package.json
├── README.md
├── tsconfig.json
└── .gitignore
```

Let's look at the key files:

#### app/layout.tsx

This is the root layout that wraps all pages:

```tsx
import type { Metadata } from "next";
import { Inter } from "next/font/google";
import "./globals.css";

const inter = Inter({ subsets: ["latin"] });

export const metadata: Metadata = {
  title: "Create Next App",
  description: "Generated by create next app",
};

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html lang="en">
      <body className={inter.className}>{children}</body>
    </html>
  );
}
```

#### app/page.tsx

This is the home page of your application:

```tsx
import Image from "next/image";

export default function Home() {
  return (
    <main className="flex min-h-screen flex-col items-center justify-between p-24">
      <div className="z-10 w-full max-w-5xl items-center justify-between font-mono text-sm lg:flex">
        {/* Content */}
      </div>
    </main>
  );
}
```

### Step 4: Create a New Page

Let's create a new page for your application:

1. Create a new folder called `about` inside the `app` directory
2. Create a `page.tsx` file inside the `about` folder:

```tsx
// app/about/page.tsx
export default function About() {
  return (
    <div className="min-h-screen flex flex-col items-center justify-center">
      <h1 className="text-4xl font-bold mb-4">About Page</h1>
      <p className="text-xl">This is my first Next.js app!</p>
    </div>
  );
}
```

Visit `http://localhost:3000/about` to see your new page.

### Step 5: Add Navigation

Let's add navigation between your pages. Update your `app/layout.tsx`:

```tsx
// app/layout.tsx
import type { Metadata } from "next";
import { Inter } from "next/font/google";
import "./globals.css";
import Link from "next/link";

const inter = Inter({ subsets: ["latin"] });

export const metadata: Metadata = {
  title: "Create Next App",
  description: "Generated by create next app",
};

export default function RootLayout({
  children,
}: Readonly<{
  children: React.ReactNode;
}>) {
  return (
    <html lang="en">
      <body className={inter.className}>
        <nav className="bg-gray-800 text-white p-4">
          <div className="container mx-auto flex gap-4">
            <Link href="/" className="hover:underline">
              Home
            </Link>
            <Link href="/about" className="hover:underline">
              About
            </Link>
          </div>
        </nav>
        <main>{children}</main>
      </body>
    </html>
  );
}
```

### Step 6: Create a Component

Algorize UI ships a card — see the quick start above to install it, or its
[component page](/docs/nextjs/card) for every variant. To understand what the
CLI writes for you, here is the same idea built by hand:

1. Create a new folder called `components` in the root of your project
2. Create a new file called `Card.tsx` inside the `components` folder:

```tsx
// components/Card.tsx
import React from "react";

interface CardProps {
  title: string;
  children: React.ReactNode;
}

export default function Card({ title, children }: CardProps) {
  return (
    <div className="border rounded-lg shadow-lg p-6 max-w-md">
      <h2 className="text-2xl font-bold mb-4">{title}</h2>
      <div>{children}</div>
    </div>
  );
}
```

Use the component in your pages:

```tsx
// app/page.tsx
import Card from "@/components/Card";
import Image from "next/image";

export default function Home() {
  return (
    <main className="flex min-h-screen flex-col items-center justify-between p-24">
      <Card title="Welcome to Next.js">
        <p className="mb-4">
          This is a simple card component that you can reuse throughout your
          application.
        </p>
        <Image
          src="/next.svg"
          alt="Next.js Logo"
          width={180}
          height={38}
          priority
        />
      </Card>
    </main>
  );
}
```

### Step 7: Fetch Data

Let's fetch some data from an API:

```tsx
// app/page.tsx
import Card from "@/components/Card";
import Image from "next/image";

interface User {
  id: number;
  name: string;
  email: string;
}

async function getUsers(): Promise<User[]> {
  // In a real app, you would fetch from an actual API
  return [
    { id: 1, name: "John Doe", email: "john@example.com" },
    { id: 2, name: "Jane Smith", email: "jane@example.com" },
  ];
}

export default async function Home() {
  const users = await getUsers();

  return (
    <main className="flex min-h-screen flex-col items-center justify-between p-24">
      <Card title="Welcome to Next.js">
        <p className="mb-4">
          This is a simple card component that you can reuse throughout your
          application.
        </p>
        <Image
          src="/next.svg"
          alt="Next.js Logo"
          width={180}
          height={38}
          priority
        />
      </Card>

      <Card title="Users">
        <ul className="space-y-2">
          {users.map((user) => (
            <li key={user.id} className="border-b pb-2">
              <h3 className="font-semibold">{user.name}</h3>
              <p className="text-gray-600">{user.email}</p>
            </li>
          ))}
        </ul>
      </Card>
    </main>
  );
}
```

### Step 8: Add Styling

Let's add some custom styling to your application:

```css
/* app/globals.css */
@tailwind base;
@tailwind components;
@tailwind utilities;

:root {
  --foreground-rgb: 0, 0, 0;
  --background-start-rgb: 214, 219, 220;
  --background-end-rgb: 255, 255, 255;
}

@media (prefers-color-scheme: dark) {
  :root {
    --foreground-rgb: 255, 255, 255;
    --background-start-rgb: 0, 0, 0;
    --background-end-rgb: 0, 0, 0;
  }
}

body {
  color: rgb(var(--foreground-rgb));
  background: linear-gradient(
      to bottom,
      transparent,
      rgb(var(--background-end-rgb))
    )
    rgb(var(--background-start-rgb));
}

@layer utilities {
  .text-balance {
    text-wrap: balance;
  }
}
```

### Step 9: Deploy Your App

To deploy your Next.js app, you can use Vercel (the creators of Next.js):

1. Push your code to GitHub
2. Sign up for a Vercel account
3. Import your repository
4. Vercel will automatically deploy your app

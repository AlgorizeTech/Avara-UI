# Quick Start

<OtherFrameworkGuide slug="first-app" label="quick start" />

Get your first {SITE_NAME} component on screen in a new Next.js app. For an existing
project, follow the [Installation guide](/docs/nextjs/installation) instead.

## 1. Create a Next.js app

```bash
npx create-next-app@latest my-app --typescript --tailwind --app
cd my-app
```

## 2. Initialize shadcn

Creates `components.json` and the `cn` helper every component imports.

<Cli command={`init --base radix --preset nova`} />

## 3. Register the registry

Tells the CLI where <code>{REGISTRY_NAMESPACE}/…</code> components live.

<Cli command={REGISTRY_ADD_ARGS} />

## 4. Add a component

<Cli command={`add card.json`} />

This writes `components/custom/blocks/CardBlock.tsx` into your project.

## 5. Use it

```tsx
// app/page.tsx
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/custom/blocks/CardBlock";

export default function Home() {
  return (
    <main className="p-24">
      <Card variant="bordered" className="w-full max-w-sm">
        <CardHeader>
          <CardTitle>Welcome</CardTitle>
          <CardDescription>Your first installed component.</CardDescription>
        </CardHeader>
        <CardContent>
          <p className="text-sm">
            Edit the file the CLI just wrote — it is yours now.
          </p>
        </CardContent>
      </Card>
    </main>
  );
}
```

Run `npm run dev` and open `http://localhost:3000`.

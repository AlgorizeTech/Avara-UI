# Quick Start

<OtherFrameworkGuide slug="first-app" label="quick start" />

Get an Algorize UI component on screen in a new React + Vite app. For an existing
project, follow the [Installation guide](/docs/reactjs/installation) instead.

## 1. Create a Vite app

```bash
npm create vite@latest my-app -- --template react-ts
cd my-app
npm install
```

## 2. Set up Tailwind and the path alias

```bash
npm install tailwindcss @tailwindcss/vite
```

```ts
// vite.config.ts
import path from "node:path";
import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: { "@": path.resolve(__dirname, "./src") },
  },
});
```

```css
/* src/index.css — replace the whole file */
@import "tailwindcss";
```

Add the alias to `compilerOptions` in both `tsconfig.json` and
`tsconfig.app.json`:

```json
{
  "compilerOptions": {
    "paths": { "@/*": ["./src/*"] }
  }
}
```

## 3. Initialize shadcn

Creates `components.json` and the `cn` helper every component imports.

<Cli command={`init --base radix --preset nova`} />

## 4. Register the registry

Tells the CLI where `@algorize-ui/…` components live.

<Cli command={`registry add @algorize-ui=https://algorize-ui.vercel.app/r/{name}.json`} />

## 5. Add a component

<Cli command={`add card.json`} />

This writes `src/components/custom/blocks/CardBlock.tsx` into your project.

## 6. Use it

```tsx
// src/App.tsx
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/custom/blocks/CardBlock";

export default function App() {
  return (
    <main className="p-24">
      <Card variant="bordered" className="w-full max-w-sm">
        <CardHeader>
          <CardTitle>Welcome</CardTitle>
          <CardDescription>Your first Algorize UI component.</CardDescription>
        </CardHeader>
        <CardContent>
          <p className="text-sm">
            Edit the file the CLI just wrote — it is yours now.
          </p>
        </CardContent>
      </Card>
    </main>
  );
}
```

Run `npm run dev` and open `http://localhost:5173`.

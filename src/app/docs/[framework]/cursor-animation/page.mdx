# Shadcn Cursor Animation

An interactive, 100% full-width and responsive custom cursor component with 11 distinct animation variants including fluid physics, particle trails, magnetic targeting, spotlight masking, and precision crosshairs.

`CursorAnimation` enhances pointer interactions over designated containers with customizable animations, seamless dark mode support, and fluid responsive physics for all devices.

## About Shadcn Cursor Animation

**What it is.** **Shadcn Cursor Animation** (`CursorAnimation` and `MainContent`) adds custom pointer effects inside any container across 11 variants: `image-trail`, `glow`, `magnetic`, `trail`, `badge`, `spotlight`, `expand`, `crosshair`, `ring`, `pulse`, and `sonar`.

**How it is built.** Using smooth LERP interpolation physics, `CursorAnimation` tracks mouse movement within its bounds with a `requestAnimationFrame` loop that runs only while the pointer is over it, supports theme colors (`primary`, `indigo`, `rose`, `emerald`, `zinc`, or hex), and adapts cleanly across light and dark modes. It listens to mouse events only and has no `prefers-reduced-motion` check. The only npm dependency is `lucide-react`.

**When to use it.** Use it for interactive hero canvases, creative agency portfolios, image showcase zones, and custom action regions.

## Works with other components

- Pair `CursorAnimation` with <DocLink to="particle-canvas">Particle Canvas</DocLink> for interactive dot-field heroes.

## How do I customize the text pill on variant="badge"?

Pass `label` alongside `variant="badge"`, for example `label="View Project"`. The pill floats beside the pointer and shows that text, and it falls back to `"Explore"` when you leave `label` out. Every other variant ignores `label`, so it has no effect unless the variant is `"badge"`.

## Can I control how many particles appear in variant="trail"?

Yes. Pass `trailCount`, which defaults to `6`. The trail records the pointer position roughly every 20 ms and keeps only the newest `trailCount` points, so a larger number gives a longer, denser tail. Only `variant="trail"` reads this prop; the other variants ignore it.

## How do I use my own pictures in the image-trail variant?

Pass an `images` array of URLs with `variant="image-trail"`. A new 140 by 180 px card spawns each time the pointer moves more than 45 px from the last one, cycling through your list in order, with about seven on screen at once. Without `images`, it uses eight remote demo photos.

## Why is the normal cursor hidden, and why can't I click links inside CursorAnimation?

The container sets `cursor-none` so the effect replaces the native cursor inside it. `MainContent` also sets `pointer-events-none`, which its children inherit. Add `pointer-events-auto` to any button or link that should stay clickable, and consider a visible focus style for it.

## Does CursorAnimation work on touch screens or with reduced motion?

It is built for mouse pointers. The component listens to `onMouseMove`, `onMouseEnter`, `onMouseLeave`, `onMouseDown` and `onMouseUp` only, has no dedicated touch handling, and does not check `prefers-reduced-motion`. Treat it as a desktop enhancement and keep important content readable without the effect.

## How do I change the CursorAnimation color and size?

Set `color` to `"primary"` (follows your `--primary` token), `"indigo"`, `"rose"`, `"emerald"`, `"zinc"` or a hex string like `"#10b981"`; unknown names fall back to primary. The container is full width and `480px` tall, or `560px` from the `sm` breakpoint, and `className` is merged with `tailwind-merge`, so `h-96` overrides it.

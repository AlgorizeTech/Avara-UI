# Apple Select

Recreates the iOS text-selection look — a translucent highlight with a lollipop handle on either end — over any string you give it.

The range is chosen by the author, not the reader: pass the full `text` and a `[start, end]` character range, and the component splits the string around it. That makes it ideal for docs, onboarding tips and marketing copy where you want to point at *part* of a sentence without a screenshot. The handles are purely decorative and are hidden from assistive tech; the text itself stays one uninterrupted string. It renders as a `<p>`, and any other HTML attribute (`className`, `style`, `id`…) is forwarded to it.

Explore the different variations of the Apple Select component — each example shows a live preview with the exact code to copy.

export const usageDefault = `import { AppleSelect } from "@/components/custom/blocks/AppleSelectBlock";

// The author picks the highlighted range — it is fixed, not draggable.
// [43, 60] covers "ability to select" (end is exclusive, like String.slice).
export default function SelectionDemo() {
  return (
    <AppleSelect
      text="Introduced with iOS 3 in June 2009 was the ability to select, copy and paste text using selection handles displayed on either end of the highlighted range."
      selection={[43, 60]}
      className="max-w-lg text-2xl font-medium tracking-tight"
    />
  );
}`;

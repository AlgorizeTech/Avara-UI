# Card Stack

A layered deck of cards featuring fluid drag-to-discard gestures, button-driven directional slide animations, and realistic depth perspective. Users can swipe cards left or right to review and discard them, with the next cards seamlessly stepping forward.

## Props Reference

<div className="overflow-x-auto my-4">
  <table>
    <thead>
      <tr>
        <th>Prop</th>
        <th>Type</th>
        <th>Default</th>
        <th>Description</th>
      </tr>
    </thead>
    <tbody>
      <tr>
        <td><code>items</code></td>
        <td><code>CardStackItem[]</code></td>
        <td><strong>Required</strong></td>
        <td>Array of card items to display in the stack.</td>
      </tr>
      <tr>
        <td><code>title</code></td>
        <td><code>string</code></td>
        <td>—</td>
        <td>Optional heading text. If omitted, the counter (e.g. <code>1 of 8</code>) is placed on the left with navigation buttons on the right.</td>
      </tr>
      <tr>
        <td><code>swipeToDismiss</code></td>
        <td><code>boolean</code></td>
        <td><code>false</code></td>
        <td>Whether to enable dragging and swiping the top card left or right to discard.</td>
      </tr>
      <tr>
        <td><code>canDismissLastCard</code></td>
        <td><code>boolean</code></td>
        <td><code>false</code></td>
        <td>Whether the last card in the stack can be swiped away/dismissed. Defaults to <code>false</code> so the final card stays in place.</td>
      </tr>
      <tr>
        <td><code>showHeader</code></td>
        <td><code>boolean</code></td>
        <td><code>true</code></td>
        <td>Whether to render the header bar (title, counter, and navigation). Set to <code>false</code> for a pure card stack.</td>
      </tr>
      <tr>
        <td><code>showNavigation</code></td>
        <td><code>boolean</code></td>
        <td><code>true</code></td>
        <td>Whether to show header navigation arrow buttons. Set to <code>false</code> for pure swipe mode.</td>
      </tr>
      <tr>
        <td><code>visibleCards</code></td>
        <td><code>number</code></td>
        <td><code>3</code></td>
        <td>Maximum number of cards visually stacked (front card + cards behind).</td>
      </tr>
      <tr>
        <td><code>slideDirection</code></td>
        <td><code>"right" | "left"</code></td>
        <td><code>"right"</code></td>
        <td>Direction the front card slides out when advancing forward via buttons.</td>
      </tr>
      <tr>
        <td><code>loop</code></td>
        <td><code>boolean</code></td>
        <td><code>false</code></td>
        <td>Whether navigation wraps around continuously or stops at the ends.</td>
      </tr>
      <tr>
        <td><code>defaultIndex</code></td>
        <td><code>number</code></td>
        <td><code>0</code></td>
        <td>Initial active index of the stack on mount.</td>
      </tr>
      <tr>
        <td><code>onCardChange</code></td>
        <td><code>(index: number) =&gt; void</code></td>
        <td>—</td>
        <td>Callback fired whenever the active card changes.</td>
      </tr>
      <tr>
        <td><code>onDismiss</code></td>
        <td><code>(item, direction) =&gt; void</code></td>
        <td>—</td>
        <td>Callback fired when a card is swiped/dismissed with the item and direction (<code>"left" | "right"</code>).</td>
      </tr>
      <tr>
        <td><code>renderCard</code></td>
        <td><code>(item, offset, isTop) =&gt; ReactNode</code></td>
        <td>—</td>
        <td>Custom render function to replace the default card body.</td>
      </tr>
      <tr>
        <td><code>cardClassName</code></td>
        <td><code>string</code></td>
        <td>—</td>
        <td>Optional custom className applied to each individual card container.</td>
      </tr>
    </tbody>
  </table>

# Profile Page

A person as a page: an aurora backdrop, frosted panels in four shapes, and a 24-hour dial that shows when they are at work — live, in their own time zone.

`ProfilePageBlock` ships four primitives rather than one monolith. `ProfilePage` is the backdrop and a 12-column grid; `GlassPanel` is one glass recipe with a `shape` that encodes hierarchy (a `slab` for the hero, a `tile` for content, a `disc` for a single number, a `capsule` for chips); `WorkdayDial` is the one element that moves; `useLocalTime` is the hook under it. Compose them with your own data — nothing has to be reshaped to fit.

## Building your own

The page above is a composition, not a component with forty props. Start from three panels and add what your data has.

```tsx
import { GlassPanel, ProfilePage, WorkdayDial } from "@/components/custom/blocks/ProfilePageBlock";

export default function Minimal() {
  return (
    <ProfilePage className="rounded-[36px]" aurora={["#f9a8d4", "#a5b4fc", "#fde68a"]}>
      <GlassPanel shape="slab" className="p-8 lg:col-span-8">
        <h1 className="text-3xl font-semibold tracking-tight">Ayesha Karim</h1>
        <p className="mt-2 text-black/60 dark:text-white/60">Design engineer at Northwind</p>
      </GlassPanel>

      <GlassPanel shape="slab" className="p-6 lg:col-span-4">
        <WorkdayDial timeZone="Asia/Dhaka" start={10} end={18} place="Dhaka" name="Ayesha" />
      </GlassPanel>

      <GlassPanel shape="disc" className="grid place-items-center lg:col-span-2">
        <p className="text-3xl font-semibold tabular-nums">128</p>
      </GlassPanel>
    </ProfilePage>
  );
}
```

Grid spans are plain Tailwind: the grid is `grid-cols-1 md:grid-cols-6 lg:grid-cols-12`, so `lg:col-span-8` is two thirds of the page on desktop and full width on a phone. The three-disc row in the example is a nested `grid grid-cols-3` inside one cell, which keeps the discs square at every width.

# MCP Server

Connect your AI assistant to the {SITE_NAME} registry. With the shadcn MCP server
it can browse, search and install components from plain-language prompts — no
copy-pasting commands.

The server is part of the shadcn CLI. It is free, needs no API key, and works with
{SITE_NAME} because our components are published as a standard shadcn registry.

## Quick start

### Step 1: Register {SITE_NAME}

Run once per project, so the server knows where to find our components:

<Cli command={REGISTRY_ADD_ARGS} />

This adds the registry to `components.json`, which you can also write by hand:

<RegistryConfig />

### Step 2: Add the MCP server

Pick your client and run the command in your project. Prefer to do it by hand? See
[Configuration](#configuration).

  <McpClientPanel client="claude">

  </McpClientPanel>
  <McpClientPanel client="cursor">

  </McpClientPanel>
  <McpClientPanel client="codex">

### Step 3: Try it

Ask your assistant:

- "Show me all components in the {REGISTRY_NAMESPACE} registry"
- "Add the hero and navbar from {REGISTRY_NAMESPACE} to my project"
- "Build a pricing page using components from {REGISTRY_NAMESPACE}"

## Configuration

Add the server to your client's MCP config. The command is the same everywhere —
only the file differs.

<McpClientTabs>
  <McpClientPanel client="claude">
    Add to `.mcp.json`, then run `/mcp` to check the connection:

    ```json
    {
      "mcpServers": {
        "shadcn": {
          "command": "npx",
          "args": ["shadcn@latest", "mcp"]
        }
      }
    }
    ```
  </McpClientPanel>
  <McpClientPanel client="cursor">
    Add to `.cursor/mcp.json`, then enable the server in Cursor Settings. A green dot
    means it is connected:

    ```json
    {
      "mcpServers": {
        "shadcn": {
          "command": "npx",
          "args": ["shadcn@latest", "mcp"]
        }
      }
    }
    ```
  </McpClientPanel>
  <McpClientPanel client="vscode">
    Add to `.vscode/mcp.json`, then click **Start** beside the server. VS Code uses
    `servers` rather than `mcpServers`:

    ```json
    {
      "servers": {
        "shadcn": {
          "command": "npx",
          "args": ["shadcn@latest", "mcp"]
        }
      }
    }
    ```
  </McpClientPanel>
  <McpClientPanel client="codex">
    Add to `.codex/config.toml` in your project (or `~/.codex/config.toml` for every project), then restart Codex:

    ```toml
    [mcp_servers.shadcn]
    command = "npx"
    args = ["shadcn@latest", "mcp"]
    ```
  </McpClientPanel>
  <McpClientPanel client="opencode">
    Add to `opencode.json`, then restart OpenCode:

    ```json
    {
      "$schema": "https://opencode.ai/config.json",
      "mcp": {
        "shadcn": {
          "type": "local",
          "command": ["npx", "shadcn@latest", "mcp"],
          "enabled": true
        }
      }
    }
    ```
  </McpClientPanel>
</McpClientTabs>

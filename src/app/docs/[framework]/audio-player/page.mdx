# Audio Player

An audio player with artwork, transport, scrubber and volume — in a hero card, a compact bar, or wrapped around the browser's native controls. Built on a plain `<audio>` element with no player library.

`AudioPlayer` is a separate component with the same visual language. It wraps a plain `<audio>` element and mirrors that element's events, so the UI stays correct when a media key, the OS, or the native controls change playback.

export const usageAudioHero = `import { AudioPlayer } from "@/components/custom/blocks/AudioPlayerBlock";

export default function PodcastHero() {
  return (

## Plyr audio

The <DocLink to="video-player">Plyr player</DocLink> from the Video Player page also has an audio layout: set `mediaType="audio"` and the card drops its video frame and sizes to the control bar. Use it when you want Plyr's control bar for both media types across a site.

export const usagePlyrAudio = `import { PlyrPlayer } from "@/components/custom/blocks/VideoPlayerPlyrBlock";

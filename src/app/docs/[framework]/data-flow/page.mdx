# Data Flow

A section that shows where the data comes from and what comes out: source cards on the left feed one node in the middle, which fans out to result cards on the right. The connectors are real curves measured from the cards, so they hold at any width; when the section first scrolls into view the sources arrive, the lines draw themselves to the core, the core lands, the lines draw on and the results arrive — then a dash keeps moving along every line.

`DataFlow` is built on <DocLink to="flowchart">Flowchart</DocLink> and <DocLink to="apple-select">Apple Select</DocLink>: the connectors are `FlowCanvas` and `FlowConnection` inside a fluid `Flowchart`, and the key phrases of the intro are selected iOS-style by `AppleSelect`; both install alongside. Every card is a named part — `Source`, `Core`, `Output` — with `Pill`, `Tag` and `Row` for the bits inside, so the content is entirely yours; the example below fills its output cards with <DocLink to="half-stars">Half Stars</DocLink> and <DocLink to="button">Button</DocLink>, which you add as you need them.

## How the lines are drawn

The section measures its cards after layout and lays a cubic curve from each source's right edge to the core's left edge, and from the core's right edge to each output's left edge. A `ResizeObserver` re-measures whenever the board changes size, so the lines follow the layout instead of being drawn for one width. Below `lg` the columns stack and the curves would have to cross the cards, so they are hidden and short dashed spines mark the flow instead.

Each curve is a `FlowConnection` from <DocLink to="flowchart">Flowchart</DocLink>, in the fluid layout this section added to it: `dashed` gives the resting line its pattern, `flowDash` sets the moving dash, `glow={false}` keeps it flat, and the draw-in on mount is the same GSAP tween the fixed canvas uses. The moving dash follows the theme's primary colour; pass `accent` to pin it.

```tsx
<DataFlow accent="#f26522" heading="From Data to Opportunities">
  …
</DataFlow>
```

### DataFlow.Pill, DataFlow.Tag, DataFlow.Row

Plain styled elements that take <code>className</code> and children: a solid black pill, a hairline chip, and a quiet grey row with its contents spaced apart. Use them inside <code>Output</code> so the cards share one vocabulary.

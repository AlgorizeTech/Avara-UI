# Flowchart / Node Builder

A declarative, highly sleek flowchart engine complete with custom responsive column channels, node action anchors, and custom vector streaming lines animated smoothly via GSAP.

This engine separates data flow layout orchestration from canvas tracking. By combining declarative standard layout structures with pre-set micro connection vectors, pipelines render cross-device flawlessly without heavy calculations crashing client frame updates.

Click any node that sits on a route to make that route the active one — GSAP redraws the stream along the SVG path.

## Best Practices & Guidelines

<div className="flex flex-col gap-4 my-6 not-prose">

    <h4 className="text-base font-semibold text-blue-900 dark:text-blue-300 mb-1">Keep ports and paths in sync</h4>
    <p className="text-blue-800 dark:text-blue-400/80 text-sm">Node positions come from Tailwind <code>left-[…]</code> / <code>top-[…]</code> classes and the routes are raw SVG coordinates, so the two are only aligned because you made them align. When you move a node, move the matching <code>M</code>/<code>L</code> coordinates with it.</p>
  </div>
  <div className="p-5 rounded-xl border border-amber-200 dark:border-amber-900/50 bg-amber-50/50 dark:bg-amber-950/20">
    <h4 className="text-base font-semibold text-amber-900 dark:text-amber-300 mb-1">Split long routes into segments</h4>
    <p className="text-amber-800 dark:text-amber-400/80 text-sm">Several <code>FlowConnection</code>s can share the same <code>id</code>. Splitting a branch into per-hop segments lets the stream animation restart at each node instead of sweeping the whole diagram at once.</p>
  </div>
</div>

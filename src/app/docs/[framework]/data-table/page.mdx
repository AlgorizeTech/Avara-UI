# Data Table

A powerful, fully-featured data table component built on top of [Table](./table) primitives. It provides built-in state management for **Global Searching, Multi-Column Sorting, Pagination, Row Selection, and Batch Actions** — giving you complete control over your table layout without forcing any data transformation.

## Soft variant

`variant="soft"` is the admin-dashboard look: a rounded panel on a hairline ring, a tinted header band, pill controls and calm round row actions, every tint mixed from the table colour. Everything below lives inside the panel — status tabs with live counts, select filters, search, a reset, the page's actions, sortable columns with a pinned actions column, a rows-per-page picker, pagination and a floating bar for the selected rows. The first example on this page is a soft table — its Usage tab is the preview's exact source.

## Best Practices & Guidelines

<div className="flex flex-col gap-4 my-6 not-prose">
  <div className="rounded-xl border border-foreground/[0.06] bg-foreground/[0.03] p-4">
    <h4 className="font-sans text-[14px] font-semibold text-foreground mb-1">Give rows a stable id</h4>
    <p className="text-[13px] leading-relaxed text-foreground/50">Selection is tracked by id, not by index, so it survives sorting and paging. If your rows have no natural key, derive one before passing the array in — an array index will unselect the wrong row as soon as the order changes.</p>
  </div>
  <div className="rounded-xl border border-primary/15 bg-primary/5 p-4">
    <h4 className="font-sans text-[14px] font-semibold text-primary mb-1">Client-side by design</h4>
    <p className="text-[13px] leading-relaxed text-foreground/50">Search, sort and paging all run over the array you pass in. For server-driven datasets, use the plain Table primitives and drive the query yourself — or keep DataTable for the current page only and supply your own footer.</p>
  </div>
  <div className="rounded-xl border border-foreground/[0.06] bg-foreground/[0.03] p-4">
    <h4 className="font-sans text-[14px] font-semibold text-foreground mb-1">Give a function sortBy an id</h4>
    <p className="text-[13px] leading-relaxed text-foreground/50">A string sortBy doubles as its own identity. When you pass an accessor function, add sortId so the active-sort indicator stays stable across re-renders.</p>
  </div>
</div>

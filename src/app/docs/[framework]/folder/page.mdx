# Folder

A tactile folder — unified skeleton cards (or your own photos) tuck behind a frosted-glass front pocket.

The back panel and its tab are one continuous squircle path, the pocket is frosted glass that tilts open in 3D, and the cards inside lift into a shallow arc on hover, tap or focus. Give it a `color` and the pocket, icon and cards all derive their shades from it in OKLCH. Pass `files` with thumbnails to show real photos, names to get hover tooltips, or switch on `interactive` to make it a drag-and-drop upload target with progress bars — that example lives on the <DocLink to="file-upload">File Upload</DocLink> page.

Explore the different variations of the Folder — each example shows a live preview with the exact code to copy. Hover a folder to open it.

## Best Practices & Guidelines

<div className="flex flex-col gap-4 my-6 not-prose">
  <div className="rounded-xl border border-foreground/[0.06] bg-foreground/[0.03] p-4">
    <h4 className="font-sans text-[14px] font-semibold text-foreground mb-1">Leave headroom above the folder</h4>
    <p className="text-[13px] leading-relaxed text-foreground/50">The fan lifts cards roughly half the folder's height above it and the arrows sit just outside its width. Give the folder that space, and avoid <code>overflow-hidden</code> on its immediate parent.</p>
  </div>
  <div className="rounded-xl border border-primary/15 bg-primary/5 p-4">
    <h4 className="font-sans text-[14px] font-semibold text-primary mb-1">Do not double up the click</h4>
    <p className="text-[13px] leading-relaxed text-foreground/50">An <code>interactive</code> folder spends its click on the file picker, so tap-to-toggle is off there. If an ancestor already handles clicks, pass <code>toggleOnClick={false}</code> and <code>focusable</code> so the fan stays keyboard-reachable.</p>
  </div>
</div>

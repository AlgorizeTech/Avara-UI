## What is a shadcn block?

A block is a larger piece of an interface than a single component: a hero, a
pricing table, a footer or a dashboard page. Avara UI lists these as website
sections. Like every other Avara UI item, a block is copied into your project
as source code, so you can edit it like any other file.

## How do I install a block?

Register the registry once with the shadcn CLI, then add a block by name with
`npx shadcn@latest add @avara-ui/name`. The CLI installs the
npm packages and the other Avara UI components that block uses. The
[Installation guide](https://avaraui.com/docs/reactjs/installation) has the one-time setup.

## Are the blocks free?

Yes. Every block is free and MIT-licensed, and needs no account or license key.

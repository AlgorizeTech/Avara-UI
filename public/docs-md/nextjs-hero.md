# Hero Sections

A collection of modern, highly composable Hero components for marketing websites. Built with Tailwind CSS and Framer Motion. This block separates layout structure from visual style through **Compound Components**, so you can write the exact same clean component structure every time.

---

## React SaaS Hero

A modern, customizable UI library designed to help you ship beautiful SaaS products faster. Packed with responsive components, clean code, and design tokens—so you can focus on building, not styling from scratch.

## Hero Section with Video Action

A complete hero section component featuring a responsive split layout and a centered call to action. Perfect for data tools and landing pages.

## Minimalist Black & White Hero

A clean, minimalist hero section with a classic black and white design. Features clear typography, checkmark highlights, and an essential statistics footer. Perfect for professional and corporate websites.

## Installation

### Copy the Component

This component handles all layout shifts via Tailwind grid utilities. You can safely copy the core `HeroBlock.tsx` and begin implementing the layouts seen above.

You can copy the full engine code directly from the **Component** tab in the Interactive Showcase at the top of the page. Place it in `components/custom/blocks/HeroBlock.tsx`.

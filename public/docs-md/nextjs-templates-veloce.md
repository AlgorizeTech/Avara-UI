Built For Production

Ships with light and dark modes wired to CSS custom properties and a built-in theme switcher, matching the rest of the library.

Every section's copy lives in dedicated content files, while changelog entries and blog posts are authored in MDX.

Configured for static HTML export with generated sitemap, robots.txt, and per-page Open Graph metadata.

Keyboard navigation, semantic landmarks, and reduced-motion fallbacks are baked into every interactive block.

# Creating Your First App

This guide will walk you through creating your first Next.js application.

## Prerequisites

Before you start, make sure you have:

- Node.js 18.17 or later installed
- A code editor (we recommend Visual Studio Code)
- A terminal or command prompt

## Step 1: Create a New Next.js App

Open your terminal and run the following command:

```bash
npx create-next-app@latest my-first-app --typescript --app
```

This command creates a new Next.js application with:

- TypeScript support
- The App Router (recommended for new projects)
- A basic project structure

Navigate to your new project directory:

```bash
cd my-first-app
```

## Step 2: Run the Development Server

Start the development server:

```bash
npm run dev
```

Visit `http://localhost:3000` in your browser to see your new Next.js app!

## Step 3: Explore the Project Structure

Your new Next.js app has the following structure:

```bash
my-first-app/
├── app/
│   ├── layout.tsx
│   └── page.tsx
├── public/
│   └── next.svg
├── styles/
│   └── globals.css
├── next.config.mjs
├── package.json
├── README.md
├── tsconfig.json
└── .gitignore
```

Let's look at the key files:

### app/layout.tsx

This is the root layout that wraps all pages:

```tsx

import "./globals.css";

const inter = Inter({ subsets: ["latin"] });

export const metadata: Metadata = {
  title: "Create Next App",
  description: "Generated by create next app",
};

export default function RootLayout({
  children,
}: Readonly) {
  return (
    
      {children}
    
  );
}
```

### app/page.tsx

This is the home page of your application:

```tsx

export default function Home() {
  return (

        {/* Content */}

  );
}
```

## Step 4: Create a New Page

Let's create a new page for your application:

1. Create a new folder called `about` inside the `app` directory
2. Create a `page.tsx` file inside the `about` folder:

```tsx
// app/about/page.tsx
export default function About() {
  return (
    
      About Page
      This is my first Next.js app!
    
  );
}
```

Visit `http://localhost:3000/about` to see your new page.

## Step 5: Add Navigation

Let's add navigation between your pages. Update your `app/layout.tsx`:

```tsx
// app/layout.tsx

import "./globals.css";

const inter = Inter({ subsets: ["latin"] });

export const metadata: Metadata = {
  title: "Create Next App",
  description: "Generated by create next app",
};

export default function RootLayout({
  children,
}: Readonly) {
  return (

              Home

              About

        {children}

  );
}
```

## Step 6: Create a Component

Let's create a reusable component:

1. Create a new folder called `components` in the root of your project
2. Create a new file called `Card.tsx` inside the `components` folder:

```tsx
// components/Card.tsx

interface CardProps {
  title: string;
  children: React.ReactNode;
}

export default function Card({ title, children }: CardProps) {
  return (
    
      {title}
      {children}
    
  );
}
```

Use the component in your pages:

```tsx
// app/page.tsx

export default function Home() {
  return (

          This is a simple card component that you can reuse throughout your
          application.

  );
}
```

## Step 7: Fetch Data

Let's fetch some data from an API:

```tsx
// app/page.tsx

interface User {
  id: number;
  name: string;
  email: string;
}

async function getUsers(): Promise {
  // In a real app, you would fetch from an actual API
  return [
    { id: 1, name: "John Doe", email: "john@example.com" },
    { id: 2, name: "Jane Smith", email: "jane@example.com" },
  ];
}

export default async function Home() {
  const users = await getUsers();

  return (

          This is a simple card component that you can reuse throughout your
          application.

          {users.map((user) => (
            
              {user.name}
              {user.email}
            
          ))}

  );
}
```

## Step 8: Add Styling

Let's add some custom styling to your application:

```css
/* app/globals.css */
@tailwind base;
@tailwind components;
@tailwind utilities;

:root {
  --foreground-rgb: 0, 0, 0;
  --background-start-rgb: 214, 219, 220;
  --background-end-rgb: 255, 255, 255;
}

@media (prefers-color-scheme: dark) {
  :root {
    --foreground-rgb: 255, 255, 255;
    --background-start-rgb: 0, 0, 0;
    --background-end-rgb: 0, 0, 0;
  }
}

body {
  color: rgb(var(--foreground-rgb));
  background: linear-gradient(
      to bottom,
      transparent,
      rgb(var(--background-end-rgb))
    )
    rgb(var(--background-start-rgb));
}

@layer utilities {
  .text-balance {
    text-wrap: balance;
  }
}
```

## Step 9: Deploy Your App

To deploy your Next.js app, you can use Vercel (the creators of Next.js):

1. Push your code to GitHub
2. Sign up for a Vercel account
3. Import your repository
4. Vercel will automatically deploy your app
